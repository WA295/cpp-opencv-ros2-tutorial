## 1. 画点、画圆

```cpp
void cv::circle(InputOutputArray img, Point center, int radius,
                const Scalar& color, int thickness = 1,
                int lineType = LINE_8, int shift = 0);
```

| 参数 | 说明 |
| --- | --- |
| `img` | 要画的图（会直接改它！想保留原图先 `clone()`） |
| `center` | 圆心 `cv::Point(x, y)` |
| `radius` | 半径（像素） |
| `color` | 颜色 `cv::Scalar(B, G, R)` |
| `thickness` | 线宽；**`-1` = 实心** |

```cpp
cv::circle(img, cv::Point(100, 200), 5, cv::Scalar(0, 255, 0), -1);   // 绿色实心点
cv::circle(img, center, 20, cv::Scalar(255, 0, 0), 2);                // 蓝色圆环
```

**颜色记忆（BGR）：**

| 想要的颜色 | Scalar 写法 |
| --- | --- |
| 红 | `Scalar(0, 0, 255)` |
| 绿 | `Scalar(0, 255, 0)` |
| 蓝 | `Scalar(255, 0, 0)` |
| 白 | `Scalar(255, 255, 255)` |
| 黑 | `Scalar(0, 0, 0)` |
| 黄 | `Scalar(0, 255, 255)` |
| 青 | `Scalar(255, 255, 0)` |
| 品红 | `Scalar(255, 0, 255)` |

**什么时候用：** 标记关键点（角点、中心、圆心）。

## 2. 画线、画箭头

```cpp
void cv::line(InputOutputArray img, Point pt1, Point pt2,
              const Scalar& color, int thickness = 1);
void cv::arrowedLine(InputOutputArray img, Point pt1, Point pt2,
                     const Scalar& color, int thickness = 1);
```

```cpp
cv::line(img, p1, p2, cv::Scalar(0, 255, 255), 2);
cv::arrowedLine(img, center, tip, cv::Scalar(0, 0, 255), 2);   // 画箭头（表示方向）
```

**什么时候用：** 连两点（灯条上下端）；`arrowedLine` 显示方向（速度、朝向）。

## 3. 画矩形

```cpp
void cv::rectangle(InputOutputArray img, Rect rect,
                   const Scalar& color, int thickness = 1);
void cv::rectangle(InputOutputArray img, Point pt1, Point pt2,
                   const Scalar& color, int thickness = 1);   // 对角两点版
```

```cpp
cv::rectangle(img, cv::Rect(x, y, w, h), cv::Scalar(0, 255, 0), 2);
cv::rectangle(img, p1, p2, cv::Scalar(255, 0, 0), -1);   // 实心块
```

**什么时候用：** 框住目标（`boundingRect` 的结果）；画 ROI 提示。

## 4. 画多边形 polylines

```cpp
void cv::polylines(InputOutputArray img, InputArrayOfArrays pts,
                   bool isClosed, const Scalar& color, int thickness = 1);
```

```cpp
std::vector<cv::Point> corners = {p1, p2, p3, p4};
cv::polylines(img, corners, true, cv::Scalar(0, 255, 0), 2);   // 闭合成四边形
```

**什么时候用：**

- 画"最小外接旋转矩形"的 4 个角点（`minAreaRect` + `rect.points`）。
- 画任意多边形轮廓。

**和 `drawContours` 的区别：** `polylines` 画的是你自己给的点集（顺序可控）；
`drawContours` 画的是 `findContours` 找到的轮廓。**画自定义四边形用 polylines。**

## 6. 写文字 putText

```cpp
void cv::putText(InputOutputArray img, const String& text, Point org,
                 int fontFace, double fontScale, Scalar color,
                 int thickness = 1, int lineType = LINE_8, bool bottomLeftOrigin = false);
```

| 参数 | 说明 |
| --- | --- |
| `text` | 要写的文字（**中文会显示成问号，OpenCV 不支持中文**） |
| `org` | 文字**左下角**的位置 |
| `fontFace` | 字体，常用 `FONT_HERSHEY_SIMPLEX`、`FONT_HERSHEY_COMPLEX` |
| `fontScale` | 字号大小（1.0 左右） |

```cpp
cv::putText(img, "yaw:12.3", cv::Point(10, 30),
            cv::FONT_HERSHEY_SIMPLEX, 0.7, cv::Scalar(0, 255, 255), 2);
cv::putText(img, std::to_string(number), cv::Point(x, y),
            cv::FONT_HERSHEY_COMPLEX, 1.0, cv::Scalar(255, 255, 255), 2);
```

**什么时候用：** 显示数字、角度、距离、调试信息（**最常用的调试手段之一**）。

> **中文怎么办？** OpenCV 的 `putText` 不支持中文。要用 `cv::freetype` 模块，
> 或者干脆用英文/数字（推荐，省事）。

## 7. 窗口

### 7.1 创建窗口

```cpp
cv::namedWindow("result", cv::WINDOW_NORMAL);   // 可缩放
cv::namedWindow("result", cv::WINDOW_AUTOSIZE); // 自动大小（默认）
```

### 7.2 显示图像

```cpp
cv::imshow("result", img);
```

### 7.3 等待按键（必须！）

```cpp
int key = cv::waitKey(1);     // 等 1ms，返回按下的键（没按返回 -1）
// int key = cv::waitKey(0);  // 无限等待按键（看单图用）
```

**新手第一坑：`imshow` 后不写 `waitKey`，窗口就是白的/不刷新。**

| 写法 | 场景 |
| --- | --- |
| `waitKey(1)` | 视频流/循环显示（不会卡） |
| `waitKey(30)` | 想按 30fps 播放 |
| `waitKey(0)` | 静态图，等你看完按键 |

### 7.4 销毁窗口

```cpp
cv::destroyWindow("result");
cv::destroyAllWindows();
```

### 7.5 常见报错

| 报错 | 原因 | 解决 |
| --- | --- | --- |
| `can't open display` | 没有图形界面（SSH/服务器） | 别用 imshow，改存文件；或开 X11 转发 |
| 窗口卡死 | `waitKey` 没调用 | 每次 imshow 后调用 |
| 窗口一闪而过 | 程序结束太快 | 用 `waitKey(0)` 或加循环 |

## 8. 调参滑条 createTrackbar

**用途：** 运行时拖动滑条改参数，不用重新编译。调阈值、面积、角度时神器。

```cpp
int cv::createTrackbar(const String& trackbarname,   // 滑条名字
                       const String& winname,        // 所属窗口
                       int* value,                   // 当前值指针（可 nullptr）
                       int count,                    // 最大值
                       TrackbarCallback onChange = 0,
                       void* userdata = 0);

int cv::getTrackbarPos(const String& trackbarname, const String& winname);
void cv::setTrackbarPos(const String& trackbarname, const String& winname, int pos);
```

### 标准用法

```cpp
int thresholdValue = 100;      // 全局变量，滑条会改它

// 建窗口（必须先有窗口）
cv::namedWindow("参数", cv::WINDOW_NORMAL);

// 建滑条：value 传 nullptr 就不会自动绑定，用 get/set 手动读写
cv::createTrackbar("threshold", "参数", nullptr, 255);
cv::setTrackbarPos("threshold", "参数", thresholdValue);   // 设初值

// 每帧读取最新值
thresholdValue = cv::getTrackbarPos("threshold", "参数");
```

> 上例里 `value` 传 `nullptr` 是校园赛项目的写法（注释说这样"减少算法压力"）。
> 也可以传 `&thresholdValue`，让 OpenCV 自动更新它。

### 参数窗口要放什么

滑条本身没有可视区域，所以要配一张"假窗口"：

```cpp
// 造一张黑图当参数窗口的画布
cv::Mat paramImg = cv::Mat::zeros(150, 600, CV_8UC3);
cv::imshow("参数", paramImg);     // 显示之后滑条才看得到
```

### 完整调参骨架

```cpp
// 构造函数里
cv::namedWindow("参数");
cv::createTrackbar("threshold", "参数", nullptr, 255);
cv::setTrackbarPos("threshold", "参数", 100);
cv::createTrackbar("minArea", "参数", nullptr, 1000);
cv::setTrackbarPos("minArea", "参数", 70);

// 每帧处理时
int thresholdValue = cv::getTrackbarPos("threshold", "参数");
int minAreaValue  = cv::getTrackbarPos("minArea", "参数");
// ... 用这些值
cv::Mat paramImg = cv::Mat::zeros(150, 600, CV_8UC3);
cv::imshow("参数", paramImg);
```

**什么时候用：** 任何"参数不好一次调对"的场景（阈值、面积、颜色范围）。

## 10. 保存图片 imwrite

```cpp
cv::imwrite("debug_01.png", img);     // 保存（后缀决定格式：png/jpg/bmp）
```

**什么时候用：**

- 没有图形界面时，**把中间结果存成文件**再看。
- 保存"认错的样本"，方便以后分析。

**技巧：** 批量存图时用计数器命名，避免同一文件反复覆盖：

```cpp
static int save_count = 0;
if (++save_count % 30 == 0) {          // 每 30 帧存一张
    cv::imwrite("debug_" + std::to_string(save_count) + ".png", mask);
}
```

## 11. 视频读写

```cpp
#include <opencv2/videoio.hpp>

// 读摄像头
cv::VideoCapture cap(0);
if (!cap.isOpened()) return;

cv::Mat frame;
while (cap.read(frame)) {
    cv::imshow("camera", frame);
    if (cv::waitKey(1) == 27) break;    // ESC 退出
}

// 读视频文件
cv::VideoCapture file("test.mp4");

// 写视频
cv::VideoWriter writer("out.avi",
    cv::VideoWriter::fourcc('M', 'J', 'P', 'G'),
    25, cv::Size(640, 480));
writer.write(frame);
```

**什么时候用：** 想把程序运行过程录下来复盘（很有用！）。

## 12. 实战套路：调试与可视化

### 套路 1：调试"看见"中间结果

识别不工作时，**每一步都画出来看一眼**：

```cpp
cv::imshow("1-原始", frame);
cv::imshow("2-差值", red_diff);
cv::imshow("3-二值", binary);
cv::imshow("4-轮廓", contour_img);
cv::waitKey(1);
```

哪一步开始不对，问题就在那。**这是排查图像问题最快的办法。**

### 套路 2：在一张图上标出所有关键信息

```cpp
cv::Mat show = frame.clone();           // 在副本上画，不破坏原图

// 画灯条
for (const auto& lb : lightbars) {
    cv::circle(show, lb.center, 3, cv::Scalar(0, 255, 0), -1);
    cv::circle(show, lb.top, 4, cv::Scalar(255, 0, 0), -1);
    cv::circle(show, lb.bottom, 4, cv::Scalar(0, 0, 255), -1);
}

// 画装甲板
for (const auto& armor : armors) {
    std::vector<cv::Point> pts;
    for (auto& p : armor.corners) pts.push_back(p);
    cv::polylines(show, pts, true, cv::Scalar(0, 255, 0), 2);
    cv::putText(show, std::to_string(armor.number),
                armor.center, cv::FONT_HERSHEY_SIMPLEX, 1.0,
                cv::Scalar(255, 255, 255), 2);
}

// 显示解算结果
cv::putText(show, "yaw:" + std::to_string(yaw),
            cv::Point(10, 30), cv::FONT_HERSHEY_SIMPLEX, 0.7,
            cv::Scalar(0, 255, 255), 2);
cv::imshow("result", show);
cv::waitKey(1);
```

### 套路 3：颜色区分不同阶段

- 绿色：识别成功、合格
- 红色：被拒绝/不合格
- 黄色：中间结果
- 蓝色：辅助线

这样一眼能看出算法在哪一步丢了目标。

### 套路 4：降频显示，别拖慢程序

```cpp
static int show_count = 0;
if (++show_count % 3 == 0) {        // 每 3 帧显示一次
    cv::imshow("result", show);
    cv::waitKey(1);
}
```

> `imshow` 和 `waitKey` 都不便宜，主循环里每帧都调可能拖慢识别。

### 套路 5：发现参数不对时，用滑条现场调

见第 8 节。**先让程序跑起来，边看边调，调好了把值写回代码。**
