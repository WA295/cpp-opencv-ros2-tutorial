## 1. 轮廓总流程

**轮廓（contour）**就是"黑白图上白色区域的边界点连成的线"。

标准流程（背下来）：

```
彩色图
  │ cvtColor 转灰度（如果用颜色分割，可跳过）
  ▼
灰度图
  │ threshold / inRange 二值化 → 得到黑白图
  ▼
二值图（白=目标，黑=背景）
  │ findContours 找轮廓
  ▼
轮廓列表 contours
  │ 逐个算特征：面积/外接矩形/角度...
  │ 用 if 筛选
  ▼
合格的目标
```

**关键前提：`findContours` 只认黑白图（单通道）。** 彩色图必须先转灰度或二值化。

## 2. findContours 找轮廓

```cpp
void cv::findContours(InputArray image, OutputArrayOfArrays contours,
                      OutputArray hierarchy, int mode, int method,
                      Point offset = Point());
void cv::findContours(InputArray image, OutputArrayOfArrays contours,
                      int mode, int method, Point offset = Point());   // 不要层级
```

| 参数 | 说明 |
| --- | --- |
| `image` | **单通道二值图**（白 255 是要找的） |
| `contours` | 输出：`vector<vector<Point>>`，每个元素是一条轮廓 |
| `hierarchy` | 输出：轮廓的层级关系（可选） |
| `mode` | 检索模式（见下） |
| `method` | 近似方式（见下） |

**mode（检索模式）：**

| 值 | 含义 | 什么时候用 |
| --- | --- | --- |
| `RETR_EXTERNAL` | 只要最外层 | **最常用**（不关心洞） |
| `RETR_LIST` | 所有轮廓，不分层级 | 都要 |
| `RETR_CCOMP` | 分两层（外/内） | 中等 |
| `RETR_TREE` | 完整树状层级 | 要分析嵌套 |

**method（近似方式）：**

| 值 | 含义 | 什么时候用 |
| --- | --- | --- |
| `CHAIN_APPROX_SIMPLE` | 压缩直线段，只留拐点 | **最常用**（省内存） |
| `CHAIN_APPROX_NONE` | 保留每个点 | 需要精细形状时 |

```cpp
std::vector<std::vector<cv::Point>> contours;
cv::findContours(binary, contours, cv::RETR_EXTERNAL, cv::CHAIN_APPROX_SIMPLE);

std::cout << "找到 " << contours.size() << " 个轮廓\n";
```

**什么时候用：** 任何"从掩码/二值图里提取独立目标"的场景。

> ⚠️ 不同 OpenCV 版本签名有差异（4.x 是上面这样，输出数组不改变输入；很老的版本会改输入）。Jazzy 自带的是 OpenCV 4.6，按上面写就对。

## 4. contourArea 面积 / arcLength 周长

```cpp
double cv::contourArea(InputArray contour, bool oriented = false);
double cv::arcLength(InputArray curve, bool closed);
```

```cpp
double area = cv::contourArea(contours[i]);          // 面积（像素平方）
double len  = cv::arcLength(contours[i], true);      // 周长
```

**什么时候用：**

- `contourArea`：按大小筛选（过滤太小的噪点、太大的背景）。**最常用的筛选特征。**
- `arcLength`：算周长（形状复杂度、`approxPolyDP` 要用）。

## 5. boundingRect 正外接矩形

```cpp
cv::Rect cv::boundingRect(InputArray array);   // 输入可以是点集或轮廓
```

返回 `Rect(x, y, width, height)`：**不倾斜**的、能刚好框住所有点的矩形。

```cpp
cv::Rect r = cv::boundingRect(contours[i]);
cv::rectangle(img, r, cv::Scalar(255, 0, 0), 2);     // 画出来
cv::Mat roi = img(r);                                // 抠出这块区域
```

**什么时候用：**

- 想"框住一个目标"（正矩形）。
- **抠 ROI**：`img(boundingRect(...))` 是屡试不爽的套路（数字识别就靠它）。
- 越界时用 `rect & imageRect` 取交集（`cv::Rect` 支持 `&` 运算符求重叠）。

## 6. minAreaRect 最小外接旋转矩形

```cpp
cv::RotatedRect cv::minAreaRect(InputArray points);
```

返回 `RotatedRect`（可以倾斜）：

| 成员 | 含义 |
| --- | --- |
| `.center` | 中心点 `Point2f` |
| `.size` | `Size2f(width, height)` |
| `.angle` | 旋转角度 |
| `.points(pts)` | 填 4 个角点到数组 |

```cpp
cv::RotatedRect rect = cv::minAreaRect(contours[i]);

cv::Point2f pts[4];
rect.points(pts);                       // 取 4 个角点
for (int k = 0; k < 4; k++)             // 画出来
    cv::line(img, pts[k], pts[(k+1)%4], cv::Scalar(0,255,0), 2);

float w = rect.size.width, h = rect.size.height;
float angle = rect.angle;
```

**`RotatedRect` 的一个重要特性：**
`size.width` 和 `size.height` 不保证哪个是"长边"。
如果点集接近竖直，可能 width > height，也可能反过来。
**所以要先把长短边归一化**（不满足就 `std::swap`），再算"高宽比"。

```cpp
float w = rect.size.width, h = rect.size.height;
if (w > h) std::swap(w, h);   // 之后 h 一定是长边
```

**什么时候用：**

- 目标会旋转（灯条是斜的）→ 必须用它。
- 要算"长宽比"来筛细长形状。
- 要取四个角点做 PnP。

## 8. approxPolyDP 多边形拟合 / convexHull 凸包

### 8.1 多边形拟合

```cpp
void cv::approxPolyDP(InputArray curve, OutputArray approxCurve,
                      double epsilon, bool closed);
```

```cpp
double eps = 0.02 * cv::arcLength(contour, true);   // 按周长的 2% 近似
std::vector<cv::Point> approx;
cv::approxPolyDP(contour, approx, eps, true);

std::cout << "这个形状有 " << approx.size() << " 个角\n";
```

**什么时候用：** 判断形状是几边形（三角形/矩形/五边形）。`approx.size()` 就是顶点数。

### 8.2 凸包

```cpp
void cv::convexHull(InputArray points, OutputArray hull);
```

**什么时候用：** 求"最外层包围形状"；判断形状是否凸；算凸缺陷。

## 9. pointPolygonTest 点与多边形关系

```cpp
double cv::pointPolygonTest(InputArray contour, Point2f pt, bool measureDist);
```

返回值：

| 返回值 | 含义 |
| --- | --- |
| 正数 | 点在多边形**内部**（`measureDist=true` 时是到边界距离） |
| 0 | 点在边界上 |
| 负数 | 点在**外部** |

**什么时候用：** 判断"某个点是不是在目标区域内"（比如准星是否对准目标）。

## 11. 直线检测

```cpp
// 标准霍夫变换
void cv::HoughLines(InputArray image, OutputArray lines,
                    double rho, double theta, int threshold);
// 概率霍夫（更实用，返回线段端点）
void cv::HoughLinesP(InputArray image, OutputArray lines,
                     double rho, double theta, int threshold,
                     double minLineLength = 0, double maxLineGap = 0);
```

```cpp
std::vector<cv::Vec4i> lines;
cv::HoughLinesP(edges, lines, 1, CV_PI/180, 50, 50, 10);
for (auto& l : lines)
    cv::line(img, cv::Point(l[0], l[1]), cv::Point(l[2], l[3]),
             cv::Scalar(0, 0, 255), 2);
```

**什么时候用：** 画面里有明显直线（车道线、边框）。**输入是先 `Canny` 得到的边缘图。**

| 参数 | 含义 |
| --- | --- |
| `threshold` | 多少票才算直线（越小越灵敏、越多误检） |
| `minLineLength` | 最短线段长度 |
| `maxLineGap` | 允许的断裂长度 |

## 12. 圆检测 HoughCircles

```cpp
void cv::HoughCircles(InputArray image, OutputArray circles,
                      int method, double dp, double minDist,
                      double param1 = 100, double param2 = 100,
                      int minRadius = 0, int maxRadius = 0);
```

```cpp
std::vector<cv::Vec3f> circles;
cv::HoughCircles(gray, circles, cv::HOUGH_GRADIENT, 1, 20, 100, 30, 5, 50);
for (auto& c : circles)
    cv::circle(img, cv::Point(c[0], c[1]), c[2], cv::Scalar(0, 255, 0), 2);
```

**参数：** `minDist` 圆心最小间距；`param2` 越小越容易检测到（也越多误检）。

**什么时候用：** 找圆形目标（不需要轮廓）。输入必须先模糊（去噪）。

## 13. 模板匹配 matchTemplate

```cpp
void cv::matchTemplate(InputArray image, InputArray templ,
                       OutputArray result, int method);
void cv::minMaxLoc(InputArray src, double* minVal, double* maxVal,
                   Point* minLoc = 0, Point* maxLoc = 0);
```

```cpp
cv::Mat result;
cv::matchTemplate(img, tmpl, result, cv::TM_CCOEFF_NORMED);

double maxVal; cv::Point maxLoc;
cv::minMaxLoc(result, nullptr, &maxVal, nullptr, &maxLoc);

if (maxVal > 0.8) {                         // 匹配度阈值
    cv::rectangle(img, maxLoc,
        cv::Point(maxLoc.x + tmpl.cols, maxLoc.y + tmpl.rows),
        cv::Scalar(0, 255, 0), 2);
}
```

**什么时候用：** 目标长得很固定（图标、固定图案）时，简单又快。
**缺点：** 不能处理旋转和缩放（除非做多尺度模板）。

## 15. 实战套路：从轮廓到目标

把上面的函数串成一个"筛选 + 配对"的完整模板：

```cpp
// 1. 二值化（前面的步骤省略）
cv::Mat binary;
cv::threshold(gray, binary, 100, 255, cv::THRESH_BINARY);

// 2. 找轮廓
std::vector<std::vector<cv::Point>> contours;
cv::findContours(binary, contours, cv::RETR_EXTERNAL, cv::CHAIN_APPROX_SIMPLE);

// 3. 逐个算特征、筛选、收进 vector
struct Bar { cv::Point2f center; cv::Point2f top, bottom; float h, w, angle; };
std::vector<Bar> bars;

for (const auto& c : contours) {
    double area = cv::contourArea(c);
    if (area < 70 || area > 5000) continue;          // 面积筛选

    cv::RotatedRect rect = cv::minAreaRect(c);
    float w = rect.size.width, h = rect.size.height;
    if (w > h) std::swap(w, h);                       // 归一：h 是长边
    if (h / w < 1.5) continue;                        // 长宽比筛选（灯条是细长的）
    if (std::abs(rect.angle) > 30) continue;          // 角度筛选

    cv::Point2f pts[4];
    rect.points(pts);
    // ... 由 pts 算出 top/bottom，填进 Bar
    bars.push_back({rect.center, top, bottom, h, w, rect.angle});
}

// 4. 两两配对
for (size_t i = 0; i < bars.size(); i++) {
    for (size_t j = i + 1; j < bars.size(); j++) {
        double d = cv::norm(bars[i].center - bars[j].center);   // 距离
        float  hRatio = std::max(bars[i].h, bars[j].h) / std::min(bars[i].h, bars[j].h);
        if (d < 200 && d / bars[i].h > 1.5 && hRatio < 1.5) {
            // 组成一对：灯条 i、j
        }
    }
}
```

**要点：**

1. **先算特征、再筛选**：`contourArea` → `minAreaRect` → 长宽比/角度。
2. **归一化长短边**：`if (w > h) swap(w, h);`。
3. **两两配对用 `j = i+1`**。
4. 距离用 `cv::norm(p1 - p2)`（点相减得到向量，`norm` 求长度）。

```cpp
double dist = cv::norm(pt1 - pt2);   // 两点距离，很方便
```

## 16. 按需求查函数

| 我想…… | 用 |
| --- | --- |
| 从二值图找目标 | `findContours` |
| 看轮廓长啥样（调试） | `drawContours` |
| 量面积 | `contourArea` |
| 量周长 | `arcLength` |
| 框住目标（正） | `boundingRect` |
| 框住目标（可斜） | `minAreaRect` + `rect.points` |

| 找直线 | `HoughLinesP`（先 Canny） |
| 找圆 | `HoughCircles` |
| 找固定图案 | `matchTemplate` |
| 抠出一块区域 | `img(rect)`（配合 boundingRect） |
| 防止 ROI 越界 | `rect & imageRect` |
