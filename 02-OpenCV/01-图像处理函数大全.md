## 1. 颜色空间转换 cvtColor

```cpp
void cv::cvtColor(InputArray src, OutputArray dst, int code, int dstCn = 0);
```

| 参数 | 说明 |
| --- | --- |
| `src` | 输入图像 |
| `dst` | 输出图像 |
| `code` | 转换码，如 `COLOR_BGR2GRAY` |
| `dstCn` | 输出通道数（0 = 自动） |

**常用转换码：**

| code | 作用 |
| --- | --- |
| `COLOR_BGR2GRAY` | 彩色 → 灰度 |
| `COLOR_BGR2RGB` | BGR → RGB |
| `COLOR_BGR2HSV` | 彩色 → HSV（找颜色用） |
| `COLOR_HSV2BGR` | HSV → BGR |
| `COLOR_GRAY2BGR` | 灰度 → 伪彩色 |
| `COLOR_BGR2Lab` | 彩色 → Lab |

```cpp
cv::Mat gray;
cv::cvtColor(img, gray, cv::COLOR_BGR2GRAY);
```

**什么时候用：**
- 做边缘/轮廓/数字识别前 → 转灰度。
- 要按颜色找目标 → 转 HSV。
- 要和别的库交换图像 → 转 RGB。

## 2. 通道操作 split / merge

```cpp
void cv::split(InputArray m, OutputArrayOfArrays mv);      // 拆分
void cv::merge(InputArrayOfArrays mv, OutputArray dst);    // 合并
```

```cpp
std::vector<cv::Mat> channels;
cv::split(img, channels);          // channels[0]=B, [1]=G, [2]=R
cv::Mat& blue  = channels[0];
cv::Mat& green = channels[1];
cv::Mat& red   = channels[2];

// 处理后再合回去
cv::Mat merged;
cv::merge(channels, merged);
```

**什么时候用：**
- 要单独处理某个颜色通道（比如"红−蓝差值找红色"）。
- 要合成自定义彩色图。
- **记忆：OpenCV 是 BGR，所以 `[0]` 蓝、`[2]` 红。**

## 3. 图像算术 add / subtract / absdiff

```cpp
void cv::add(InputArray a, InputArray b, OutputArray dst);        // 加（饱和）
void cv::subtract(InputArray a, InputArray b, OutputArray dst);   // 减（饱和）
void cv::absdiff(InputArray a, InputArray b, OutputArray dst);    // 绝对差
void cv::multiply(InputArray a, InputArray b, OutputArray dst);   // 乘
void cv::divide(InputArray a, InputArray b, OutputArray dst);     // 除
```

**"饱和"是什么意思？** 结果超过 255 就按 255 算，低于 0 按 0 算（不会溢出回绕）。

```cpp
cv::Mat red_diff;
cv::subtract(channels[2], channels[0], red_diff);   // 红 − 蓝：突出红色

cv::Mat diff;
cv::absdiff(frame1, frame2, diff);                  // 两帧的差异（运动检测）
```

| 函数 | 什么时候用 |
| --- | --- |
| `subtract` | **突出某种颜色**：目标通道 − 干扰通道 |
| `absdiff` | 比较两帧/两图差异（运动、变化检测） |
| `add` | 提高亮度、叠加 |
| `multiply` | 做遮罩、调对比度 |

> 也可以用运算符重载：`cv::Mat c = a - b;`（同样饱和）。但**显式写函数更清楚**。

## 4. 位运算 bitwise

```cpp
void cv::bitwise_and(InputArray a, InputArray b, OutputArray dst, InputArray mask = noArray());
void cv::bitwise_or(...);
void cv::bitwise_not(InputArray a, OutputArray dst);      // 取反
void cv::bitwise_xor(...);
```

| 函数 | 作用 | 什么时候用 |
| --- | --- | --- |
| `bitwise_and` | 与 | **用掩码抠图**：`bitwise_and(img, img, out, mask)` |
| `bitwise_or` | 或 | 合并多个掩码（如红色两段 HSV 范围） |
| `bitwise_not` | 取反 | 黑变白、白变黑 |
| `bitwise_xor` | 异或 | 找差异 |

**掩码抠图（重要套路）：**

```cpp
cv::Mat mask, result;
cv::inRange(hsv, low, high, mask);
cv::bitwise_and(img, img, result, mask);   // 只保留 mask 为白的区域
```

## 5. 滤波去噪

### 5.1 高斯模糊

```cpp
void cv::GaussianBlur(InputArray src, OutputArray dst,
                      Size ksize, double sigmaX, double sigmaY = 0,
                      int borderType = BORDER_DEFAULT);
```

| 参数 | 说明 |
| --- | --- |
| `ksize` | 核大小，**必须是奇数**，如 `Size(5,5)`、`Size(9,9)` |
| `sigmaX` | 水平标准差（0 = 根据核自动算） |

```cpp
cv::GaussianBlur(src, dst, cv::Size(9, 9), 0);
```

**什么时候用：** 图像有噪点，处理前先模糊。核越大越模糊、越平滑，但细节也越少。

### 5.2 均值模糊

```cpp
void cv::blur(InputArray src, OutputArray dst, Size ksize);
```

**什么时候用：** 最简单的平滑（比高斯快，但边缘更糊）。

### 5.3 中值滤波

```cpp
void cv::medianBlur(InputArray src, OutputArray dst, int ksize);   // ksize 奇数
```

**什么时候用：** **椒盐噪声**（黑白噪点）特别有效，比高斯更适合。

### 5.4 双边滤波

```cpp
void cv::bilateralFilter(InputArray src, OutputArray dst, int d,
                         double sigmaColor, double sigmaSpace);
```

**什么时候用：** 想"平滑但保留边缘"（磨皮效果）。

> **选择指南：** 一般噪点 → GaussianBlur；椒盐噪点 → medianBlur；保边缘 → bilateralFilter。

## 6. 阈值

### 6.1 固定阈值

```cpp
double cv::threshold(InputArray src, OutputArray dst,
                     double thresh, double maxval, int type);
```

| 参数 | 说明 |
| --- | --- |
| `thresh` | 阈值 |
| `maxval` | 超过阈值时赋的值（通常 255） |
| `type` | 阈值方式（见下） |

| type | 效果 |
| --- | --- |
| `THRESH_BINARY` | 大于阈值 → maxval，否则 0 |
| `THRESH_BINARY_INV` | 反色（大于 → 0，否则 maxval） |
| `THRESH_TRUNC` | 大于阈值 → 阈值，否则不变 |
| `THRESH_TOZERO` | 小于阈值 → 0，否则不变 |
| `THRESH_OTSU` | **自动算阈值**（与上面按位或，如 `THRESH_BINARY\|THRESH_OTSU`） |
| `THRESH_TRIANGLE` | 三角法自动阈值 |

```cpp
cv::Mat bin;
cv::threshold(gray, bin, 100, 255, cv::THRESH_BINARY);       // 固定阈值 100

cv::Mat otsu;
cv::threshold(gray, otsu, 0, 255, cv::THRESH_BINARY | cv::THRESH_OTSU);  // 自动阈值
```

**什么时候用：** 把灰度图按亮度分成"要/不要"两部分。**OTSU 省去手调阈值的痛苦**（光照均匀时效果很好）。

**输入必须是单通道（灰度图）！** 彩色图要先 `cvtColor`。

### 6.2 自适应阈值

```cpp
void cv::adaptiveThreshold(InputArray src, OutputArray dst,
                           double maxValue, int adaptiveMethod,
                           int thresholdType, int blockSize, double C);
```

```cpp
cv::adaptiveThreshold(gray, dst, 255,
    cv::ADAPTIVE_THRESH_MEAN_C, cv::THRESH_BINARY, 31, 5);
```

**什么时候用：** 光照**不均匀**（一边亮一边暗）时，全局阈值不行，用自适应 —— 每个小区域自己算阈值。

## 7. 颜色范围 inRange

```cpp
void cv::inRange(InputArray src, InputArray lowerb, InputArray upperb, OutputArray dst);
```

```cpp
cv::Mat hsv, mask;
cv::cvtColor(img, hsv, cv::COLOR_BGR2HSV);
cv::inRange(hsv, cv::Scalar(0, 100, 100), cv::Scalar(10, 255, 255), mask);
```

**参数：** 三通道的上下界（H、S、V）。

**HSV 分量范围（OpenCV）：**

| 分量 | 范围 | 含义 |
| --- | --- | --- |
| H 色调 | 0~180 | 颜色种类（红色跨 0，所以常两段合并） |
| S 饱和度 | 0~255 | 颜色浓不浓 |
| V 明度 | 0~255 | 亮不亮 |

**什么时候用：** 按颜色找东西（比"通道相减"更抗光照）。**"抠出某种颜色 → 掩码"的标准做法。**

## 8. 形态学

```cpp
void cv::erode(InputArray src, OutputArray dst, InputArray kernel);     // 腐蚀
void cv::dilate(InputArray src, OutputArray dst, InputArray kernel);    // 膨胀
void cv::morphologyEx(InputArray src, OutputArray dst, int op, InputArray kernel);
cv::Mat cv::getStructuringElement(int shape, Size ksize);               // 生成核
```

```cpp
cv::Mat kernel = cv::getStructuringElement(cv::MORPH_RECT, cv::Size(5, 5));
cv::erode(mask, mask, kernel);        // 腐蚀：白色区域缩小，去掉小噪点
cv::dilate(mask, mask, kernel);       // 膨胀：白色区域扩大，连接断裂

cv::morphologyEx(mask, mask, cv::MORPH_CLOSE, kernel);   // 闭运算
cv::morphologyEx(mask, mask, cv::MORPH_OPEN, kernel);    // 开运算
```

| 操作 | 效果 | 什么时候用 |
| --- | --- | --- |
| 腐蚀 erode | 白缩小、黑扩大 | 去掉小白点、断开细连接 |
| 膨胀 dilate | 白扩大 | 连接断开的部分、加粗 |
| 开运算 open | 先腐蚀后膨胀 | **去小噪点**（去白点） |
| 闭运算 close | 先膨胀后腐蚀 | **补小洞、连断线** |
| 形态学梯度 | 膨胀−腐蚀 | 取轮廓 |

**记忆口诀：** 开运算"去白点"，闭运算"补黑洞"。

## 9. 边缘检测

### 9.1 Canny（最常用）

```cpp
void cv::Canny(InputArray image, OutputArray edges,
               double threshold1, double threshold2, int apertureSize = 3);
```

```cpp
cv::Mat edges;
cv::Canny(gray, edges, 50, 150);      // 两个阈值：小的连边缘，大的定强边缘
```

**什么时候用：** 想找"轮廓边缘"。阈值越大边缘越少。

### 9.2 Sobel / Laplacian

```cpp
void cv::Sobel(InputArray src, OutputArray dst, int ddepth,
               int dx, int dy, int ksize = 3);
void cv::Laplacian(InputArray src, OutputArray dst, int ddepth, int ksize = 1);
```

```cpp
cv::Sobel(gray, gx, CV_16S, 1, 0);     // 水平方向梯度
cv::Sobel(gray, gy, CV_16S, 0, 1);     // 垂直方向梯度
cv::convertScaleAbs(gx, gx);           // 转回 8U 显示
```

**什么时候用：** 想要"梯度/方向"信息时（Canny 内部就用了梯度）。日常找轮廓用 Canny 就够。

## 10. 几何变换

### 10.1 resize（缩放）

```cpp
void cv::resize(InputArray src, OutputArray dst, Size dsize,
                double fx = 0, double fy = 0, int interpolation = INTER_LINEAR);
```

| 参数 | 说明 |
| --- | --- |
| `dsize` | 目标尺寸 `Size(宽,高)`；给 `Size()` 时用 fx/fy 比例 |
| `fx, fy` | 缩放比例（0.5 = 缩小一半） |
| `interpolation` | 插值方式（见下） |

| 插值 | 什么时候用 |
| --- | --- |
| `INTER_LINEAR` | 默认，放大缩小都行 |
| `INTER_NEAREST` | **缩小/像素级操作**（快，不产生新灰度） |
| `INTER_CUBIC` | 放大时更平滑（慢） |
| `INTER_AREA` | **缩小首选**（效果最好，避免摩尔纹） |

```cpp
cv::Mat small;
cv::resize(img, small, cv::Size(320, 240));
cv::resize(img, small, cv::Size(), 0.5, 0.5, cv::INTER_AREA);   // 缩小一半
```

**什么时候用：** 加速处理（缩小）、统一尺寸（喂模型，如 `Size(20,28)`）、放大显示。

### 10.2 仿射变换（旋转/平移/缩放）

```cpp
cv::Mat M = cv::getRotationMatrix2D(center, angle, scale);   // 旋转矩阵
cv::warpAffine(src, dst, M, dst.size());
```

### 10.3 透视变换（"摆正"梯形）

```cpp
// 找 4 个角点之间的关系
cv::Mat M = cv::getPerspectiveTransform(src_pts, dst_pts);
cv::warpPerspective(src, dst, M, dst.size());
```

**什么时候用：** 相机有角度、图是斜的，想"俯视图"摆正。代码识别里不常用，知道有这个即可。

## 11. 直方图与均衡化

```cpp
void cv::equalizeHist(InputArray src, OutputArray dst);   // 直方图均衡化（必须灰度）
cv::Mat hist;
cv::calcHist(&gray, 1, channels, mask, hist, 1, histSize, ranges);
```

**什么时候用：**

- `equalizeHist`：图像太暗/对比度太低时增强对比（但可能放大噪声）。
- `calcHist`：分析亮度分布（高级用法）。

## 12. 按需求查函数

| 我想…… | 用这些函数 |
| --- | --- |
| 彩色图转灰度 | `cvtColor(..., COLOR_BGR2GRAY)` |
| 单独看某个颜色通道 | `split` |
| 突出红色/蓝色 | `subtract`（红−蓝 / 蓝−红） |
| 按颜色抠出区域 | `cvtColor(BGR2HSV)` + `inRange` |
| 去掉噪点 | `GaussianBlur` / `medianBlur` |
| 把图变黑白 | `threshold`（可加 `THRESH_OTSU`） |
| 光照不均时二值化 | `adaptiveThreshold` |
| 去小白点 | `morphologyEx(MORPH_OPEN)` |
| 补小洞/连断线 | `morphologyEx(MORPH_CLOSE)` |
| 找边缘 | `Canny` |
| 缩放图片 | `resize` |
| 只处理图像一小块 | `img(roi)` 取 ROI |
| 用掩码只保留一部分 | `bitwise_and` + `mask` |
| 增强对比度 | `equalizeHist` |
| 比较两帧差异 | `absdiff` |
