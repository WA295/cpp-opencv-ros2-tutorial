## 1. 输出与格式化

### std::cout（打印）

**头文件：** `<iostream>`
**作用：** 输出到屏幕。

```cpp
std::cout << "hello" << std::endl;         // endl 会换行并刷新
std::cout << "a=" << a << " b=" << b << "\n";  // 推荐用 "\n"
```

| 要点 | 说明 |
| --- | --- |
| `<<` | 可以连着串很多内容 |
| `std::endl` vs `"\n"` | `endl` 强制刷新缓冲（慢），普通换行用 `"\n"` |
| `std::cerr` | 输出到"错误流"，常用于报错信息 |

**什么时候用：** 调试、显示信息。**程序卡住时，打印是最好的定位工具。**

### 格式化输出

**头文件：** `<iomanip>`

```cpp
#include <iomanip>
std::cout << std::fixed << std::setprecision(2) << 3.14159;   // 3.14
```

| 函数/操纵符 | 作用 |
| --- | --- |
| `std::fixed` | 用小数形式（不用科学计数法） |
| `std::setprecision(n)` | 保留 n 位小数 |
| `std::setw(n)` | 设置下一次输出的最小宽度 |

**什么时候用：** 想让打印的数字整齐好看时（日志里对齐）。

### printf（C 风格）

**头文件：** `<cstdio>`

```cpp
printf("x=%.3f, n=%d\n", 3.14159, 42);
```

| 占位符 | 类型 |
| --- | --- |
| `%d` | int |
| `%ld` / `%lld` | long / long long |
| `%f` | float/double |
| `%.2f` | 保留 2 位小数 |
| `%c` | char |
| `%s` | C 字符串 |
| `%p` | 指针 |

**什么时候用：** 想"一行搞定、格式可控"的调试打印；或老代码里。

## 2. 数学计算

**头文件：** `<cmath>`

| 函数 | 作用 | 例子 | 什么时候用 |
| --- | --- | --- | --- |
| `std::sqrt(x)` | 开平方 | `sqrt(16) == 4` | 算距离（勾股定理） |
| `std::pow(b, e)` | 求 b 的 e 次方 | `pow(2, 3) == 8` | 求平方、幂 |
| `std::abs(x)` / `fabs(x)` | 绝对值 | `abs(-3) == 3` | 比较差值大小 |
| `std::atan2(y, x)` | 由 (x,y) 求角度（弧度） | 见下 | **求方向/倾角必用** |
| `std::atan(x)` / `asin` / `acos` | 反三角 | `atan(1)` | 只有单值时 |
| `std::sin/cos/tan(x)` | 三角（参数是弧度） | `cos(0) == 1` | 角度换算 |
| `std::floor(x)` | 向下取整 | `floor(2.9) == 2` | 取整 |
| `std::ceil(x)` | 向上取整 | `ceil(2.1) == 3` | 取整 |
| `std::round(x)` | 四舍五入 | `round(2.5) == 3` | 取整 |
| `std::fmod(a, b)` | 浮点取余 | `fmod(5.5, 2) == 1.5` | 角度归一 |
| `std::hypot(a, b)` | √(a²+b²) | `hypot(3,4) == 5` | 算距离（更安全） |

### atan2 详解（重点）

```cpp
double dx = p2.x - p1.x;
double dy = p2.y - p1.y;

// 求 p1→p2 的方向角（弧度），范围 -π ~ π
double rad = std::atan2(dy, dx);
double deg = rad * 180.0 / M_PI;      // 转成角度
```

**为什么用 atan2 而不是 atan？**
`atan(dy/dx)` 只能得到 -90°~90°，而且 dx=0 时会除零。
`atan2(dy, dx)` 能正确处理四个象限，dx=0 也安全。**记住：求角度一律 atan2。**

**实战对应：** 校园赛里求灯条倾角 `atan2(dx,dy)`、求目标偏角 `atan2(tx,tz)`。

### 常量

```cpp
M_PI            // 3.14159265358979...（有些编译器要 #define _USE_MATH_DEFINES）
CV_PI           // OpenCV 里的 π（用 OpenCV 时推荐）
std::numbers::pi  // C++20
```

## 3. 字符串处理

**头文件：** `<string>`

| 函数 | 作用 | 例子 | 什么时候用 |
| --- | --- | --- | --- |
| `s.size()` / `s.length()` | 长度 | `"abc".size() == 3` | 判空/循环 |
| `s.empty()` | 是否为空 | `s.empty()` | 先检查再用 |
| `s[i]` / `s.at(i)` | 访问字符 | `s[0]` | 逐字符处理 |
| `s + t` | 拼接 | `"a" + "b"` | 组字符串 |
| `s += t` | 追加 | `s += "!"` | 累积 |
| `s.substr(pos, len)` | 子串 | `"hello".substr(0,2) == "he"` | 截取 |
| `s.find(t)` | 查找（返回下标或 npos） | `s.find("ll")` | 查找 |
| `s.replace(pos, len, t)` | 替换 | `s.replace(0,1,"H")` | 修改 |
| `s.c_str()` | 转 C 字符串 | 传给 `printf` | 与 C 接口交互 |
| `std::to_string(x)` | 数字 → 字符串 | `to_string(3.14)` | 拼日志 |
| `std::stoi(s)` | 字符串 → int | `stoi("123")` | 解析 |
| `std::stod(s)` | 字符串 → double | `stod("3.14")` | 解析 |

### 拼接数字的小技巧

`std::to_string(3.14159)` 会得到 `"3.141590"`（6 位小数）。
想只显示 2 位，用 `stringstream`：

```cpp
#include <sstream>
#include <iomanip>
std::stringstream ss;
ss << std::fixed << std::setprecision(2) << 3.14159;
std::string s = ss.str();      // "3.14"
```

或者像校园赛代码里的野路子：`to_string(x).substr(0, 6)`（截断，简单但可能截出 "3.141"）。

## 4. 容器操作

### 4.1 vector（动态数组）

**头文件：** `<vector>`

| 操作 | 作用 | 例子 |
| --- | --- | --- |
| `v.push_back(x)` | 尾部添加 | `v.push_back(1);` |
| `v.emplace_back(...)` | 尾部就地构造（效率略高） | `v.emplace_back(1,2);` |
| `v.pop_back()` | 删最后一个 | `v.pop_back();` |
| `v.size()` | 元素个数 | `for(i=0;i<v.size();i++)` |
| `v.empty()` | 是否为空 | `if(v.empty()) return;` |
| `v[i]` / `v.at(i)` | 访问 | `v.at(0)`（会检查越界） |
| `v.front()` / `v.back()` | 首/尾元素 | `v.back()` |
| `v.clear()` | 清空 | `v.clear();` |
| `v.resize(n)` | 改大小 | `v.resize(10);` |
| `v.begin()` / `v.end()` | 迭代器（配合算法） | `sort(v.begin(), v.end());` |

**什么时候用：** 数量不定的一批数据（灯条、轮廓、点集……）。**实战里最常见的容器。**

### 4.2 map / unordered_map（键值对）

**头文件：** `<map>` 或 `<unordered_map>`

```cpp
std::map<std::string, int> ages;
ages["Tom"] = 18;              // 插入/修改
int a = ages["Tom"];           // 读取（不存在会插入默认值！）
ages.count("Tom");             // 是否存在（0 或 1）
ages.find("Tom");              // 找迭代器
for (const auto& [name, age] : ages) { ... }   // C++17 遍历
```

| 选择 | 特点 |
| --- | --- |
| `std::map` | 按 key 排序，查找 O(log n) |
| `std::unordered_map` | 哈希，平均 O(1)，更快但无序 |

**什么时候用：** 需要"根据名字/编号查数据"时。

### 4.3 pair（一对数据）

**头文件：** `<utility>`

```cpp
std::pair<int, double> p{1, 3.14};
p.first;     // 1
p.second;    // 3.14
std::make_pair(2, 5.0);
```

## 5. 算法（排序/查找/最值）

**头文件：** `<algorithm>`

| 函数 | 作用 | 例子 | 什么时候用 |
| --- | --- | --- | --- |
| `std::sort(b, e)` | 排序（升序） | `sort(v.begin(), v.end());` | 排序 |
| `std::sort(b, e, cmp)` | 自定义排序 | `sort(v.begin(), v.end(), [](int a,int b){return a>b;});` | 降序/按字段 |
| `std::min(a, b)` / `max(a, b)` | 两个值的最值 | `max(1,2)` | 比较 |
| `std::min_element(b,e)` / `max_element` | 找最值位置 | `*max_element(v.begin(),v.end())` | 找最大元素 |
| `std::find(b, e, x)` | 查找元素 | `find(v.begin(),v.end(),5)` | 找是否存在 |
| `std::count(b, e, x)` | 统计出现次数 | `count(v.begin(),v.end(),1)` | 计数 |
| `std::count_if(b,e,fn)` | 条件计数 | 统计满足条件的个数 | 筛选统计 |
| `std::swap(a, b)` | 交换 | `swap(width, height);` | 交换两值 |
| `std::reverse(b, e)` | 反转 | `reverse(v.begin(),v.end());` | 反序 |
| `std::clamp(x, lo, hi)` | 夹到区间 | `clamp(x, 0.0, 255.0)` | 防越界（C++17） |
| `std::all_of(b,e,fn)` / `any_of` / `none_of` | 全部/任一/都不满足 | 条件判断 | 检查集合 |
| `std::fill(b, e, x)` | 填充 | `fill(v.begin(),v.end(),0);` | 初始化 |
| `std::max_element` 组合 `std::distance` | 最大值的下标 | `distance(v.begin(), max_element(...))` | 找索引 |

**lambda 表达式（配合算法用）：**

```cpp
// [捕获列表](参数){ 函数体 }
sort(v.begin(), v.end(), [](int a, int b){ return a > b; });  // 降序

int threshold = 100;
auto it = find_if(v.begin(), v.end(), [threshold](int x){ return x > threshold; });
```

**什么时候用：** 不想手写循环时。`sort`、`min/max`、`swap`、`clamp` 最常用。

## 6. 类型转换

| 函数/写法 | 作用 | 例子 | 什么时候用 |
| --- | --- | --- | --- |
| `static_cast<T>(x)` | 常规转换 | `static_cast<int>(3.9)` | **首选**，明确又安全 |
| 隐式转换 | 自动 | `double d = 1;` | 小转大，安全 |
| `(int)x` | C 风格 | 不推荐 | 老代码 |
| `std::to_string(x)` | 数字→字符串 | 见第 3 节 | 拼接 |
| `std::stoi/stod` | 字符串→数字 | 见第 3 节 | 解析 |
| `std::stoi(s, nullptr, 16)` | 16 进制解析 | `stoi("ff",nullptr,16)==255` | 解析进制 |

**注意事项：**

- `double` → `int` 是**截断**（3.9→3），不是四舍五入。要四舍五入用 `std::round`。
- 大范围转小范围（如 `int` 转 `unsigned char`）要小心溢出。

## 7. 时间与计时

**头文件：** `<chrono>`

```cpp
#include <chrono>

// 计时（测某段代码耗时）
auto t1 = std::chrono::steady_clock::now();
// ... 要测的代码 ...
auto t2 = std::chrono::steady_clock::now();
auto ms = std::chrono::duration_cast<std::chrono::milliseconds>(t2 - t1).count();
std::cout << "耗时 " << ms << " ms\n";
```

| 时钟 | 特点 | 什么时候用 |
| --- | --- | --- |
| `steady_clock` | 单调递增，不受系统时间调整影响 | **测耗时首选** |
| `system_clock` | 墙上时间（可转成日期） | 要真实时间戳时 |
| `high_resolution_clock` | 最高精度（通常就是上面之一） | 一般用 steady |

**常用时长单位：** `nanoseconds` `microseconds` `milliseconds` `seconds`。

**C 风格（老代码常见）：** `<ctime>` 的 `clock()`、`time(0)`。

**什么时候用：** 性能分析（找出哪一步慢）、超时判断、限频。

## 8. 文件读写

**头文件：** `<fstream>`

```cpp
#include <fstream>
#include <string>

// 读：一行一行读
std::ifstream fin("data.txt");
if (!fin.is_open()) { std::cout << "打不开文件\n"; return; }
std::string line;
while (std::getline(fin, line)) {
    std::cout << line << "\n";
}

// 写
std::ofstream fout("out.txt");
fout << "hello " << 123 << "\n";

// 追加（不覆盖）
std::ofstream fout2("out.txt", std::ios::app);
```

| 操作 | 写法 |
| --- | --- |
| 打开读 | `std::ifstream fin("a.txt");` |
| 打开写（覆盖） | `std::ofstream fout("a.txt");` |
| 打开写（追加） | `std::ofstream fout("a.txt", std::ios::app);` |
| 是否打开成功 | `fin.is_open()` / `if(!fin)` |
| 读一行 | `std::getline(fin, line);` |
| 关闭 | 自动（析构时）或 `fin.close();` |

**什么时候用：** 保存日志、读配置、读数据集。**注意：路径写错是最常见的坑，记得检查 `is_open()`。**

## 9. 内存与智能指针

**头文件：** `<memory>`

| 用法 | 作用 | 什么时候用 |
| --- | --- | --- |
| `std::make_shared<T>(args)` | 创建共享指针 | **优先用这个** |
| `std::shared_ptr<T> p = ...` | 多个指针共享同一对象 | 回调间共享、ROS 消息 |
| `std::make_unique<T>(args)` | 独占指针 | 一个对象只有一个主人 |
| `p.get()` | 取原始指针 | 传给需要裸指针的接口 |
| `p.use_count()` | 被引用次数 | 调试 |
| `p.reset()` | 释放 | 手动释放 |

```cpp
auto node = std::make_shared<CampusNode>();
auto msg = std::make_shared<sensor_msgs::msg::Image>();
```

**什么时候用：** 几乎总是 —— 它能自动释放内存，避免泄漏和手动 `delete`。

**老式裸 new/delete（了解即可）：**

```cpp
Type* p = new Type();   // 申请
delete p;               // 释放（忘了就内存泄漏）
Type* arr = new Type[10];
delete[] arr;           // 数组要用 delete[]
```

## 10. 多线程基础

**头文件：** `<thread>` `<mutex>` `<atomic>`

```cpp
#include <thread>
#include <mutex>
#include <atomic>

std::mutex mtx;
int shared = 0;
std::atomic<int> counter{0};     // 原子变量，简单计数不用锁

void worker() {
    for (int i = 0; i < 1000; i++) {
        std::lock_guard<std::mutex> lock(mtx);   // 自动加锁/解锁
        shared++;
        counter++;                                // 原子操作
    }
}

int main() {
    std::thread t1(worker), t2(worker);
    t1.join();   // 等线程结束
    t2.join();
    std::cout << shared << "\n";
}
```

| 函数/类型 | 作用 | 什么时候用 |
| --- | --- | --- |
| `std::thread t(func)` | 开新线程 | 想让两件事"同时"跑 |
| `t.join()` | 等线程结束 | **必须调用**，否则程序会崩 |
| `std::mutex` | 互斥锁 | 多线程改同一数据 |
| `std::lock_guard` | 自动锁（RAII） | **推荐用这个**，不用手动 unlock |
| `std::atomic<T>` | 原子变量 | 简单计数/标志位 |

**新手注意：** 多线程最大的坑是"数据竞争"（两个线程同时改一个变量）。
不确定就**先别用多线程**，单线程跑通再说。

## 11. 错误处理

### try / catch（异常）

```cpp
try {
    throw std::runtime_error("出错了");   // 抛出
} catch (const std::exception& e) {
    std::cout << "捕获到: " << e.what() << "\n";   // 捕获
}
```

**头文件：** `<stdexcept>`（`runtime_error`、`invalid_argument`、`out_of_range`）

**什么时候用：** 可能失败的操作用 try/catch；ROS 2 里更常用**返回错误码 + 日志**而不是异常。

### assert（调试断言）

**头文件：** `<cassert>`

```cpp
assert(width > 0 && "宽度必须为正");   // 调试版不满足会中止并打印
```

**注意：** 发布版（`-DNDEBUG`）会自动禁用，不要用它做必须执行的检查。

### 错误码风格（ROS 2 常用）

```cpp
bool ok = cv::solvePnP(...);
if (!ok) {
    RCLCPP_WARN(this->get_logger(), "solvePnP 失败");
    return;
}
```
