## 1. 消息是什么

**消息（message）= 一个固定格式的数据结构。**

- 每个消息类型有一个名字，如 `tdt_interface/msg/SendData`。
- 消息里有一系列带类型的字段，像一张表格。
- 消息用 `.msg` 文件定义，编译后生成 C++/Python 代码。

```
话题（频道）
   └── 传输的消息（格式固定）
          └── .msg 文件（定义格式）
```

**类比：** 话题是快递站，消息是包裹，`.msg` 是"包裹必须包含哪些东西"的规定。

## 2. .msg 文件语法

### 2.1 字段定义

```
类型 字段名
```

例子：

```
float32 yaw          # 角度
int32 health         # 血量
bool is_weakened     # 是否被削弱
string name          # 名字
```

**规则：**

- 每行一个字段。
- `#` 后面是注释。
- **字段名用小写加下划线**（ROS 2 惯例）。
- 没有分号，没有逗号。

### 2.2 完整示例

```
# 这是注释
std_msgs/Header header      # 标准头（时间戳等）

uint64 request_id           # 请求编号
bool accepted               # 是否受理
bool activated              # 是否激活
```

### 2.3 数组

```
int32[7] enemy_healths      # 固定长度 7 的数组
float32[] samples           # 变长数组（像 vector）
uint8[] data                # 变长字节数组（图像数据常用）
```

| 写法 | 含义 | C++ 对应 |
| --- | --- | --- |
| `int32[7] a` | 固定长度数组 | `std::array<int32_t,7>` |
| `int32[] a` | 变长数组 | `std::vector<int32_t>` |

### 2.4 嵌套消息

字段类型可以是**另一个消息类型**：

```
std_msgs/Header header          # 标准消息
geometry_msgs/Point position    # 几何消息
tdt_interface/AutoAimState state    # 本包内的另一个消息
```

- `std_msgs`、`geometry_msgs`、`sensor_msgs` 是 ROS 2 自带的"标准消息包"。
- `tdt_interface/AutoAimState` 是自定义包里的消息。
- 还支持跨包引用（`包名/消息名`）。

### 2.5 常量

消息里可以定义常量（不是字段）：

```
uint8 MODE_AUTO = 0
uint8 MODE_MANUAL = 1
uint8 mode
```

在代码里用：`MyMsg::MODE_AUTO`。**什么时候用：** 字段取值是枚举时，用常量更清楚。

## 3. 内置消息类型速查

### 3.1 基本类型

| .msg 类型 | C++ 类型 | 含义 |
| --- | --- | --- |
| `bool` | `bool` | 真假 |
| `int8/16/32/64` | `int8_t...int64_t` | 有符号整数 |
| `uint8/16/32/64` | `uint8_t...uint64_t` | 无符号整数 |
| `float32` | `float` | 单精度 |
| `float64` | `double` | 双精度 |
| `string` | `std::string` | 字符串 |
| `byte` | `uint8_t` | 字节（等价 uint8） |
| `wstring` | `std::u16string` | 宽字符串（少用） |

### 3.2 标准消息包（最常用的）

| 消息 | 用途 | 关键字段 |
| --- | --- | --- |
| `std_msgs/Header` | 消息头 | `stamp`（时间戳）、`frame_id`（坐标系） |
| `std_msgs/String` | 字符串 | `data` |
| `std_msgs/Int32` / `Float32` | 单值 | `data` |
| `std_msgs/Bool` | 布尔 | `data` |
| `geometry_msgs/Point` | 点 | `x, y, z` |
| `geometry_msgs/Vector3` | 向量 | `x, y, z` |
| `geometry_msgs/Twist` | 速度 | `linear{x,y,z}, angular{x,y,z}` |
| `geometry_msgs/Pose` | 位姿 | `position, orientation` |
| `geometry_msgs/TwistStamped` | 带时间戳的速度 | `header, twist` |
| `sensor_msgs/Image` | 图像（原始） | `header, height, width, encoding, data` |
| `sensor_msgs/CompressedImage` | 压缩图像 | `header, format, data` |
| `sensor_msgs/CameraInfo` | 相机参数 | `k, d, width, height` |
| `sensor_msgs/PointCloud2` | 点云 | 复杂，用到再查 |
| `nav_msgs/Odometry` | 里程计 | `pose, twist` |

**怎么查一个类型的字段？**

```bash
ros2 interface show sensor_msgs/msg/CameraInfo
```

## 4. 创建一个消息包

以校园赛的 `tdt_interface` 为例，一步步来。

### 4.1 目录结构

```
tdt_interface/
├── CMakeLists.txt
├── package.xml
└── msg/
    ├── AutoAimFrame.msg
    ├── AutoAimState.msg
    ├── RuneRequest.msg
    ├── RuneResult.msg
    └── SendData.msg
```

### 4.2 package.xml

```xml
<?xml version="1.0"?>
<package format="3">
  <name>tdt_interface</name>
  <version>0.0.1</version>
  <description>消息定义</description>
  <maintainer email="you@example.com">you</maintainer>
  <license>Apache-2.0</license>

  <buildtool_depend>ament_cmake</buildtool_depend>
  <buildtool_depend>rosidl_default_generators</buildtool_depend>

  <!-- 消息里用到的标准消息包 -->
  <depend>std_msgs</depend>
  <depend>sensor_msgs</depend>
  <depend>geometry_msgs</depend>
  <depend>builtin_interfaces</depend>

  <exec_depend>rosidl_default_runtime</exec_depend>

  <!-- 关键：声明这是消息包 -->
  <member_of_group>rosidl_interface_packages</member_of_group>

  <export>
    <build_type>ament_cmake</build_type>
  </export>
</package>
```

### 4.3 CMakeLists.txt

```cmake
cmake_minimum_required(VERSION 3.16)
project(tdt_interface)

find_package(ament_cmake REQUIRED)
find_package(std_msgs REQUIRED)          # 消息用到的依赖都要找
find_package(sensor_msgs REQUIRED)
find_package(geometry_msgs REQUIRED)
find_package(builtin_interfaces REQUIRED)
find_package(rosidl_default_generators REQUIRED)

# 核心：把 .msg 编译成代码
rosidl_generate_interfaces(${PROJECT_NAME}
  "msg/SendData.msg"
  "msg/AutoAimState.msg"
  "msg/AutoAimFrame.msg"
  "msg/RuneRequest.msg"
  "msg/RuneResult.msg"
  DEPENDENCIES builtin_interfaces std_msgs sensor_msgs geometry_msgs
)

install(DIRECTORY msg DESTINATION share/${PROJECT_NAME}/)

ament_package()
```

**要点：**

- `rosidl_generate_interfaces` 是消息包的"发动机"，列出所有 `.msg`。
- `DEPENDENCIES` 写消息里用到的包（漏了会编译报错）。
- 每加一个 `.msg` 文件，都要加进这里。

### 4.4 用命令行快速建包（可选）

```bash
cd ~/campus_ws/src
ros2 pkg create --build-type ament_cmake tdt_interface
mkdir -p tdt_interface/msg
# 然后照上面改 package.xml 和 CMakeLists.txt，再写 .msg 文件
```

## 5. 编译与验证

```bash
cd ~/campus_ws
source /opt/ros/jazzy/setup.bash
colcon build --packages-select tdt_interface
source install/setup.bash
```

**验证：**

```bash
ros2 interface list | grep tdt_interface      # 出现了吗

```

```
float yaw
float pitch
bool if_shoot
```

**能 `show` 出来就说明消息编译成功了。**

## 6. 在 C++ 里使用消息

### 6.1 头文件命名规则

`.msg` 文件名转成 C++ 头文件的规则：**大驼峰 → 下划线小写**。

| .msg | C++ 头文件 |
| --- | --- |
| `SendData.msg` | `tdt_interface/msg/send_data.hpp` |
| `AutoAimFrame.msg` | `tdt_interface/msg/auto_aim_frame.hpp` |
| `AutoAimState.msg` | `tdt_interface/msg/auto_aim_state.hpp` |

```cpp
#include <tdt_interface/msg/send_data.hpp>
#include <tdt_interface/msg/auto_aim_frame.hpp>
```

### 6.2 类型名

```cpp
tdt_interface::msg::SendData
tdt_interface::msg::AutoAimFrame
```

### 6.3 声明依赖

**package.xml：**

```xml
<depend>tdt_interface</depend>
```

**CMakeLists.txt：**

```cmake
find_package(tdt_interface REQUIRED)
ament_target_dependencies(你的可执行 tdt_interface)
```

### 6.4 创建、填写、发送

```cpp
tdt_interface::msg::SendData msg;      // 创建
msg.yaw = 12.3f;                       // 填字段
msg.pitch = -2.5f;
msg.if_shoot = true;

pub_->publish(msg);                    // 发送
```

### 6.5 订阅、读取

```cpp
void onFrame(const tdt_interface::msg::AutoAimFrame::SharedPtr msg)
{
    float yaw = msg->state.yaw_degrees;     // 嵌套字段
    double fx = msg->camera_info.k[0];      // 数组字段
}
```

## 7. 在 Python 里使用消息

```python
# 导入（包名.msg.消息名）
from tdt_interface.msg import SendData, AutoAimFrame

# 创建并填写
msg = SendData()
msg.yaw = 12.3
msg.pitch = -2.5
msg.if_shoot = True

pub.publish(msg)

# 接收
def callback(msg: AutoAimFrame):
    print(msg.state.yaw_degrees)
```

**Python 需要：**

```bash
pip install 包名        # 或
colcon build --packages-select 包名
source install/setup.bash
```

## 8. 实战：拆解 tdt_interface

校园赛的 5 个消息，从"谁发给谁"角度看：

| 消息 | 方向 | 内容 |
| --- | --- | --- |
| `AutoAimFrame` | 游戏 → 算法 | 图像 + 相机参数 + 自身状态（**同帧**） |
| `AutoAimState` | 游戏 → 算法 | 自身状态（从 frame 拆出来） |
| `SendData` | 算法 → 游戏 | 云台角度 + 射击许可 |
| `RuneRequest` | 算法 → 游戏 | 叫符请求 |
| `RuneResult` | 游戏 → 算法 | 符受理/增益结果 |

### 8.1 AutoAimFrame 的设计思路

```
std_msgs/Header header
tdt_interface/AutoAimState state        # 嵌套状态
sensor_msgs/CameraInfo camera_info      # 嵌套相机参数
sensor_msgs/Image image                 # 原始图（与下面二选一）
sensor_msgs/CompressedImage compressed_image
float32 capture_to_publish_ms           # 延迟统计
```

**学到的设计技巧：**

1. **用 `Header` 带时间戳** —— 让接收方能判断数据新旧。
2. **把相关数据放一个消息里** —— 图像/内参/状态同帧，避免"配不上"。
3. **给延迟字段** —— 让算法能评估时效。
4. **两种图像二选一** —— 灵活（实测用 compressed 省带宽）。

### 8.2 SendData 的设计思路

```
float32 yaw       # 世界光轴角
float32 pitch     # 向下为正，±60°
bool if_shoot     # 射击许可
```

**学到的设计技巧：**

1. **字段少而明确** —— 控制指令越简单越不容易错。
2. **在注释里写清楚方向和单位** —— 坐标系约定是最容易出错的地方。
3. **把"能不能开火"和"往哪打"分开** —— 让执行端自己决定是否真正开火。

## 9. 常见错误

| 错误 | 原因 | 解决 |
| --- | --- | --- |
| `ros2 interface show` 找不到类型 | 没编译/没 source | 编译消息包 + source |
| 编译报 "找不到 std_msgs" | 依赖没写 | package.xml 加 `<depend>std_msgs</depend>`，CMake 加 `find_package` + `DEPENDENCIES` |
| `#include` 报红/找不到 | 头文件名规则不对 | 大驼峰→下划线小写（`SendData.msg` → `send_data.hpp`） |
| 新加的消息没生效 | 忘了加进 `rosidl_generate_interfaces` | 加进去重新编译 |
| 类型不匹配 | C++ 里 int 用了 float | 看生成的头文件字段类型 |
| 消息字段访问出错 | 消息是指针 | 用 `->` 而不是 `.` |
| 发出去没人收 | 消息定义两边不一致 | 双方用**同一份** .msg（复制包或同步） |

**最重要的一条：接口变了，两边都要重新编译！** 否则会因为"类型哈希不同"而收不到数据。

## 10. 设计消息的建议

1. **一个消息只装一类数据**：`SendData` 只管控制，不要塞状态。
2. **一定要带 `Header`**：时间戳 + frame_id，便于对时和调试。
3. **注释写清单位和坐标约定**：`float32 yaw  # 度, 顺时针正`。
4. **优先复用标准消息**：`geometry_msgs/Point` 别自己写一个 x/y/z。
5. **数组长度固定就写死**：`int32[7]` 比 `int32[]` 更明确。
6. **版本兼容要小心**：改了字段，所有用它的包都要重编。
7. **命名清晰**：`if_shoot` 比 `shoot` 好（一看就是 bool）。
