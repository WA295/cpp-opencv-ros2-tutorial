## 1. 目标与准备

**最终目标：** 一个节点 `my_vision`，它：

1. 订阅 `/camera/image_raw/compressed`（压缩图像）；
2. 解码成 OpenCV Mat；
3. 转灰度、算平均亮度；
4. 把亮度发布到 `/image_brightness`（`std_msgs/Float32`）；
5. 显示图像窗口（可选）。

**环境要求：**

```bash
# 确认 ROS 2 装好
ls /opt/ros/            # 应该看到 jazzy
source /opt/ros/jazzy/setup.bash

# 确认 OpenCV 装好
pkg-config --modversion opencv4
```

## 3. 第二步：创建包

```bash
cd ~/my_ws/src
ros2 pkg create --build-type ament_cmake my_vision --dependencies rclcpp sensor_msgs std_msgs
```

生成的结构：

```
my_ws/src/my_vision/
├── CMakeLists.txt
├── package.xml
├── include/my_vision/
└── src/
```

- `--dependencies` 自动把依赖写进两份配置，省事。
- 我们要用 OpenCV，需要手动再加（下一步）。

## 4. 第三步：写代码

创建 `src/my_vision/src/vision_node.cpp`：

```cpp
#include <rclcpp/rclcpp.hpp>
#include <sensor_msgs/msg/compressed_image.hpp>
#include <std_msgs/msg/float32.hpp>
#include <opencv2/opencv.hpp>
#include <functional>

class VisionNode : public rclcpp::Node
{
public:
    VisionNode() : Node("vision_node")
    {
        // 订阅图像
        image_sub_ = this->create_subscription<sensor_msgs::msg::CompressedImage>(
            "/camera/image_raw/compressed", 1,
            std::bind(&VisionNode::imageCallback, this, std::placeholders::_1));

        // 发布亮度
        brightness_pub_ = this->create_publisher<std_msgs::msg::Float32>(
            "/image_brightness", 10);

        RCLCPP_INFO(this->get_logger(), "vision_node 已启动，等待图像……");
    }

private:
    void imageCallback(const sensor_msgs::msg::CompressedImage::SharedPtr msg)
    {
        RCLCPP_INFO_ONCE(this->get_logger(), "第一次收到图像！");

        // 1. 解码
        cv::Mat img = cv::imdecode(msg->data, cv::IMREAD_COLOR);
        if (img.empty()) {
            RCLCPP_WARN(this->get_logger(), "解码失败");
            return;
        }

        // 2. 转灰度 + 算平均亮度
        cv::Mat gray;
        cv::cvtColor(img, gray, cv::COLOR_BGR2GRAY);
        cv::Scalar mean = cv::mean(gray);

        // 3. 发布
        std_msgs::msg::Float32 out;
        out.data = static_cast<float>(mean[0]);
        brightness_pub_->publish(out);

        // 4. 显示（没有图形界面就注释掉）
        static int count = 0;
        if (++count % 3 == 0) {
            cv::putText(img, "brightness: " + std::to_string((int)mean[0]),
                        cv::Point(10, 30), cv::FONT_HERSHEY_SIMPLEX,
                        0.8, cv::Scalar(0, 255, 0), 2);
            cv::imshow("vision", img);
            cv::waitKey(1);
        }
    }

    rclcpp::Subscription<sensor_msgs::msg::CompressedImage>::SharedPtr image_sub_;
    rclcpp::Publisher<std_msgs::msg::Float32>::SharedPtr brightness_pub_;
};

int main(int argc, char** argv)
{
    rclcpp::init(argc, argv);
    auto node = std::make_shared<VisionNode>();
    rclcpp::spin(node);
    rclcpp::shutdown();
    return 0;
}
```

**用到的知识点串一遍：**

| 代码 | 对应知识 |
| --- | --- |
| `class VisionNode : public rclcpp::Node` | 节点 |
| `create_subscription<T>(话题, 队列, 回调)` | 订阅 + 回调 |
| `create_publisher<T>(话题, 队列)` | 发布 |
| `msg->data` | 访问消息字段 |
| `imdecode` | OpenCV 解码 |
| `RCLCPP_INFO/WARN/ONCE` | 日志 |
| `this->get_logger()` | 日志器 |

## 5. 第四步：配置依赖

### 5.1 package.xml

打开 `my_vision/package.xml`，确认有：

```xml
<depend>rclcpp</depend>
<depend>sensor_msgs</depend>
<depend>std_msgs</depend>
```

OpenCV 不是 ROS 包，不用写在这里。

### 5.2 CMakeLists.txt

找到/修改相关内容：

```cmake
# 找依赖
find_package(ament_cmake REQUIRED)
find_package(rclcpp REQUIRED)
find_package(sensor_msgs REQUIRED)
find_package(std_msgs REQUIRED)
find_package(OpenCV REQUIRED)          # 新增：找 OpenCV

# 生成可执行文件
add_executable(vision_node src/vision_node.cpp)

# 声明 ROS 依赖
ament_target_dependencies(vision_node
  rclcpp
  sensor_msgs
  std_msgs
)

# 链接 OpenCV
target_link_libraries(vision_node ${OpenCV_LIBS})

# 安装
install(TARGETS vision_node
  DESTINATION lib/${PROJECT_NAME}
)

ament_package()
```

**三个必须对应：**

| 位置 | 内容 |
| --- | --- |
| `add_executable` | 可执行文件名 + 源文件路径 |
| `ament_target_dependencies` | 用到的 ROS 包 |
| `install` | 装到 `lib/包名/` 下（`ros2 run` 才能找到） |

## 6. 第五步：编译

```bash
cd ~/my_ws
source /opt/ros/jazzy/setup.bash
colcon build --packages-select my_vision
```

**成功的标志：**

```
Summary: 1 package finished [x.xx s]
```

**失败怎么办？**

- 看报错第一行 + 行号（见"编程入门"篇）。
- 常见：`find_package(OpenCV)` 没加 → 找不到 `opencv2/opencv.hpp`。
- 常见：`ament_target_dependencies` 漏了 `std_msgs` → 找不到 `std_msgs/msg/float32.hpp`。
- 常见：源文件路径写错 → `add_executable` 找不到文件。

## 8. 第七步：加功能（发布）

已经加了。如果想再加"发布一帧检测到的画面"或"发布处理后图像"，参考：

```cpp
// 发布原始图像（需要 sensor_msgs/msg/image.hpp）
image_pub_ = this->create_publisher<sensor_msgs::msg::Image>("/debug_image", 1);

// 填写（比较繁琐，知道有这回事即可；实际项目多用压缩图）

out.height = img.rows;
out.width = img.cols;
out.encoding = "bgr8";
out.step = img.cols * img.channels();
out.data.assign(img.data, img.data + img.total() * img.channels());
image_pub_->publish(out);
```

## 9. 第八步：加参数与日志

### 9.1 把阈值变成参数

```cpp
// 构造函数里
this->declare_parameter("brightness_scale", 1.0);   // 声明

// 回调里读取
double scale = this->get_parameter("brightness_scale").as_double();
out.data = static_cast<float>(mean[0] * scale);
```

运行时改：

```bash
ros2 run my_vision vision_node --ros-args -p brightness_scale:=2.0
ros2 param set /vision_node brightness_scale 2.0    # 动态改
```

### 9.2 日志用对级别

```cpp
RCLCPP_INFO_ONCE(this->get_logger(), "第一次接收到图像");   // 只打一次
RCLCPP_INFO_THROTTLE(this->get_logger(), *this->get_clock(), 2000,
                     "亮度 %.1f", mean[0]);                // 每 2 秒最多一条

if (img.empty()) {
    RCLCPP_WARN(this->get_logger(), "解码失败");          // 有问题时
}
```

**高频回调里一定要用 `THROTTLE` 或 `ONCE`，否则日志会拖慢程序。**

## 10. 没有真实话题怎么办：自己发给自己

测试时没有游戏/摄像头，可以手动发一个假图像话题。

### 方法 A：用命令行发一个空消息（不够真实）

```bash
ros2 topic pub /camera/image_raw/compressed \
  sensor_msgs/msg/CompressedImage "{data: []}"
```

### 方法 B：写一个小发布者（推荐）

```cpp
// fake_publisher.cpp
#include <rclcpp/rclcpp.hpp>
#include <sensor_msgs/msg/compressed_image.hpp>
#include <opencv2/opencv.hpp>
#include <chrono>

using namespace std::chrono_literals;

class FakePub : public rclcpp::Node {
public:
    FakePub() : Node("fake_pub") {
        pub_ = this->create_publisher<sensor_msgs::msg::CompressedImage>(
            "/camera/image_raw/compressed", 1);
        timer_ = this->create_wall_timer(33ms, [this]() {   // ~30fps
            cv::Mat img(480, 640, CV_8UC3, cv::Scalar(40, 40, 40));
            cv::circle(img, cv::Point(320, 240), 100,
                       cv::Scalar(0, 0, 255), -1);            // 画个红圆
            std::vector<uchar> buf;
            cv::imencode(".jpg", img, buf);

            sensor_msgs::msg::CompressedImage msg;
            msg.format = "jpeg";
            msg.data = buf;
            pub_->publish(msg);
        });
    }
private:
    rclcpp::Publisher<sensor_msgs::msg::CompressedImage>::SharedPtr pub_;
    rclcpp::TimerBase::SharedPtr timer_;
};

int main(int argc, char** argv) {
    rclcpp::init(argc, argv);
    rclcpp::spin(std::make_shared<FakePub>());
    rclcpp::shutdown();
    return 0;
}
```

把它加进 CMakeLists，编译运行，就能独立测试你的视觉节点了。

> **这是非常重要的能力：把"上游"替换成假的，单独测"下游"。**
> 真项目里也常这么做（录 bag、写模拟器）。

## 11. 排错清单

| 现象 | 检查 |
| --- | --- |
| `ros2 run` 找不到包 | source 了吗？编译了吗？包名/可执行名对吗？ |
| 编译报找不到头文件 | `find_package` + `ament_target_dependencies` 加了吗？ |
| 运行后立刻退出 | 是不是忘了 `rclcpp::spin`？ |
| 没收到任何图像 | `ros2 topic list` 有话题吗？`topic hz` 有频率吗？domain 对吗？ |
| 窗口不显示 | 有没有 `imshow` + `waitKey`？有 DISPLAY 吗？ |
| 改了代码没生效 | 重新 `colcon build` + 重新 `source` |
| 卡死 | 是不是在回调里死循环/等锁？ |
| 段错误 | `imdecode` 结果判空了吗？数组越界？ |

## 总结：一个节点的"标准骨架"

以后你写任何新节点，都可以从这份模板开始：

```cpp
class XxxNode : public rclcpp::Node
{
public:
    XxxNode() : Node("xxx_node")
    {
        // 1. 参数
        // 2. 订阅
        // 3. 发布
        // 4. 定时器（可选）
    }

private:
    // 回调们
    // 成员变量（订阅、发布、缓存数据）

    rclcpp::Subscription<...>::SharedPtr sub_;
    rclcpp::Publisher<...>::SharedPtr pub_;
};

int main(int argc, char** argv)
{
    rclcpp::init(argc, argv);
    rclcpp::spin(std::make_shared<XxxNode>());
    rclcpp::shutdown();
    return 0;
}
```

**把这套骨架用到需要的地方，你就已经会写 ROS 2 节点了。**
