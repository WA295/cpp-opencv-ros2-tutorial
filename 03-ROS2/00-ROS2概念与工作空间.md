## 1. ROS 2 是什么

ROS = **R**obot **O**perating **S**ystem（机器人操作系统）。
它**不是**一个操作系统，而是**一套让不同程序互相通信、协作的框架**。

### 1.1 为什么需要它

假设你要做一个机器人，里面有：

- 摄像头程序（出图像）
- 识别程序（看图，出目标位置）
- 控制程序（根据目标位置，出电机指令）
- 显示程序（把状态画出来）
- 记录程序（把数据存下来）

如果每个程序都自己写 TCP/共享内存/序列化…… 会累死，而且改一个全得改。

ROS 2 的做法：**大家约定好"消息格式"和"频道"，各写各的、互不干扰。**

```
摄像头程序 ──发"图像"到 /camera/image──► 识别程序
识别程序  ──发"目标"到 /target────────► 控制程序
控制程序  ──发"速度"到 /cmd_vel──────► 电机驱动
```

**任何程序都可以随时加入/退出，不影响别人。**

### 1.2 ROS 1 与 ROS 2

| | ROS 1 | ROS 2 |
| --- | --- | --- |
| 通信 | 自研 TCP | **DDS**（工业级） |
| 实时性 | 弱 | 强 |
| 多机/安全 | 弱 | 强 |
| 现状 | 已停止维护 | **主流**（本教程用 ROS 2 Jazzy） |

**你现在学的、用的都是 ROS 2。**

## 2. 五个核心概念

### 2.1 节点（Node）

**一个节点 = 一个独立运行的程序/进程。**

- 每个节点只做一件事（摄像头节点、识别节点、控制节点）。
- 节点有名字，比如 `campus_node`。

```cpp
class CampusNode : public rclcpp::Node {
public:
    CampusNode() : Node("campus_node") { ... }   // 节点名
};
```

### 2.2 话题（Topic）

**话题 = 有名字的"数据频道"，收发数据的通道。**

- 名字用 `/` 开头，比如 `/camera/image_raw/compressed`。
- 话题是**单向**的：有人发，有人收。
- 一个话题可以有多个发布者、多个订阅者。

### 2.3 消息（Message）

**消息 = 在话题上传输的"数据包"，格式固定。**

- 比如 `sensor_msgs/msg/CompressedImage`（压缩图像）、`std_msgs/msg/String`（字符串）。
- 消息里有很多"字段"，像一张表格。
- 消息定义用 `.msg` 文件写（见 `03-消息定义与接口包`）。

### 2.4 服务（Service）

**服务 = "请求-应答"式的通信（像打电话）。**

- 客户端发请求 → 服务端处理后返回结果。
- 和话题的区别：话题是"广播"（不知道谁在听），服务是"点名"（等对方回复）。

```
话题：像收音机广播 —— 一直播，谁听谁收
服务：像打电话 —— 拨通、说话、等回答
```

### 2.5 参数（Parameter）

**参数 = 节点的"配置项"，运行时可以改。**

```cpp
this->declare_parameter("threshold", 100);          // 声明
int t = this->get_parameter("threshold").as_int();  // 读取
// 命令行改：ros2 param set /campus_node threshold 150
```

### 2.6 还有个"动作"（Action）

**动作 = 长时间的任务，可以中途反馈进度、中途取消。**
（比如"导航到 A 点"这种要跑很久的任务。）新手先了解，用到了再看。

| 概念 | 一句话 | 类比 |
| --- | --- | --- |
| 节点 | 一个程序 | 一个人 |
| 话题 | 数据频道 | 广播电台 |
| 消息 | 数据包 | 一封信 |
| 服务 | 请求-应答 | 打电话 |
| 参数 | 配置项 | 设置菜单 |
| 动作 | 长任务 | 外卖订单（有进度） |

## 3. 发布/订阅通信模型

这是 ROS 2 最核心、最常用的模型：

```
发布者（Publisher）                    订阅者（Subscriber）
   │  往话题 /autoaim/frame 发消息          │
   │  ──────────────────────────────────►  │
   │                                        │
   发完就不管（不知道谁在收）              收到就自动执行"回调函数"
```

### 3.1 三个关键角色

| 角色 | 干什么 | C++ 写法 |
| --- | --- | --- |
| 话题名 | 约定在哪通信 | `"/autoaim/frame"` |
| 消息类型 | 约定发什么格式 | `tdt_interface::msg::AutoAimFrame` |
| QoS | 约定通信规则 | 可靠/尽力、队列深度 |

### 3.2 回调（Callback）

订阅者收到消息后**自动执行**的函数叫回调。

```cpp
// 收到消息 → 自动调用 imageCallback
void imageCallback(const sensor_msgs::msg::CompressedImage::SharedPtr msg) {
    // msg 就是收到的数据
}
```

### 3.3 一个话题可以有多个发布者/订阅者

```
发布者A ─┐
发布者B ─┼──►  /话题名  ──┬──► 订阅者1
发布者C ─┘                └──► 订阅者2
```

**好处：** 加一个新功能只要"订阅话题"，不用改别人的代码。

## 4. DDS 与 ROS_DOMAIN_ID

### 4.1 DDS 是什么

ROS 2 底层用 **DDS**（数据分发服务）通信。你不需要直接学 DDS，
但要知道它带来几个特性：

- **自动发现**：节点一启动，自动找到同一网络里的其他节点，不用配 IP。
- **QoS**：可以精细控制可靠性、队列、时效。
- **多机**：同一网络内的机器可以互相通信。

### 4.2 ROS_DOMAIN_ID：频道号

**同一台机器上可能有很多 ROS 系统在跑，怎么互不干扰？用 domain（域）。**

- `ROS_DOMAIN_ID` 相同的节点才能互相通信。
- 默认是 `0`。
- 两台电脑/两个程序必须用**同一个** `ROS_DOMAIN_ID` 才能通。

```bash
export ROS_DOMAIN_ID=7     # 切到 7 号频道
```

**校园赛就是靠它：** 游戏和你的程序都用默认 `0`（或都设成 7），才能收到彼此的消息。

### 4.3 常见通信问题排查

| 问题 | 检查 |
| --- | --- |
| 收不到消息 | 两边 `ROS_DOMAIN_ID` 一样吗？ |
| 跨机器不通 | 网络通吗？防火墙？`ROS_AUTOMATIC_DISCOVERY_RANGE`？ |
| 时有时无 | QoS 不匹配？队列太浅？ |

## 5. 工作空间与包

### 5.1 三层的目录结构

```
工作空间（workspace）
└── src/
    ├── 包 A（package）
    │   ├── package.xml
    │   ├── CMakeLists.txt
    │   └── src/...
    └── 包 B
```

| 层级 | 是什么 | 例子 |
| --- | --- | --- |
| 工作空间 | 一个"项目文件夹"，统一编译 | `campus_ws`、`tdt_ros_ws` |
| 包（package） | ROS 2 的最小组织单元，一个功能模块 | `campus_vision`、`tdt_interface` |
| 文件 | 源码、配置 | `main.cpp` |

### 5.2 为什么以"包"为单位

- 包可以单独编译（`--packages-select`）。
- 包可以被别的包依赖（`<depend>tdt_interface</depend>`）。
- 包有版本、许可证、维护者信息。

### 5.3 两种包类型

| 类型 | 用什么写 | 什么时候用 |
| --- | --- | --- |
| `ament_cmake` | C++ | 性能要求高、要和 C++ 库交互 |
| `ament_python` | Python | 快速原型、脚本类 |

**消息包**也用 `ament_cmake`（即使只有 .msg 文件）。

## 6. package.xml 与 CMakeLists

一个包必须有两份"身份证"：

### 6.1 package.xml —— "我是谁、我依赖谁"

```xml
<package format="3">
  <name>campus_vision</name>
  <version>0.0.0</version>
  <description>视觉识别节点</description>
  <maintainer email="you@example.com">you</maintainer>
  <license>Apache-2.0</license>

  <buildtool_depend>ament_cmake</buildtool_depend>
  <depend>rclcpp</depend>
  <depend>sensor_msgs</depend>

  <export>
    <build_type>ament_cmake</build_type>
  </export>
</package>
```

### 6.2 CMakeLists.txt —— "怎么编译"

```cmake
cmake_minimum_required(VERSION 3.8)
project(campus_vision)

find_package(ament_cmake REQUIRED)
find_package(rclcpp REQUIRED)
find_package(sensor_msgs REQUIRED)

add_executable(campus_node src/main.cpp)
ament_target_dependencies(campus_node rclcpp sensor_msgs)

install(TARGETS campus_node DESTINATION lib/${PROJECT_NAME})
ament_package()
```

### 6.3 两者的对应关系（重要）

**package.xml 里写了依赖，CMakeLists 里也要写；两边都写上才算完整。**

| package.xml | CMakeLists |
| --- | --- |
| `<depend>rclcpp</depend>` | `find_package(rclcpp REQUIRED)` + `ament_target_dependencies(... rclcpp)` |

漏了会怎样：

- package.xml 漏了 → 别的机器装不上/依赖顺序不对。
- CMakeLists 漏了 → 编译时找不到头文件/链接不上。

## 7. 从源码到运行：完整流程

```
① 创建/获取包（src/ 下）
        │
② colcon build          ← 编译
        │
③ source install/setup.bash   ← 加载环境
        │
④ ros2 run 包名 可执行名  ← 运行
```

```bash
cd ~/campus_ws
source /opt/ros/jazzy/setup.bash

colcon build --packages-select campus_vision

source install/setup.bash
ros2 run campus_vision campus_node
```

**为什么每一步都要？**

| 步骤 | 不做会怎样 |
| --- | --- |
| `source /opt/ros/jazzy/setup.bash` | 命令 `ros2`/`colcon` 都找不到 |
| `colcon build` | 没有可执行文件 |
| `source install/setup.bash` | `ros2 run` 找不到你的包 |
| `ROS_DOMAIN_ID` 一致 | 能运行但收不到游戏消息 |

## 8. 环境变量速查

| 变量 | 作用 | 常用值 |
| --- | --- | --- |
| `ROS_DOMAIN_ID` | 通信频道号 | `0`（默认） |
| `ROS_DISTRO` | 发行版名称 | `jazzy`（自动设置） |
| `RMW_IMPLEMENTATION` | 用哪套 DDS | `rmw_fastrtps_cpp`（默认） |
| `ROS_AUTOMATIC_DISCOVERY_RANGE` | 发现范围 | `LOCALHOST` / `SUBNET` |
| `ROS_LOG_DIR` | 日志目录 | 自定义 |

查看当前环境：

```bash
printenv | grep ROS
```

## 9. 新手常见问题

| 问题 | 原因 | 解决 |
| --- | --- | --- |
| `ros2: command not found` | 没 source | `source /opt/ros/jazzy/setup.bash` |
| `Package 'xxx' not found` | 没编译或没 source | 编译 + `source install/setup.bash` |
| 改了代码没变化 | 没重新编译 | `colcon build --packages-select 包名` |
| 收不到消息 | domain 不一致 / 话题名错 | 检查两边 `ROS_DOMAIN_ID`；`ros2 topic list` |
| 编译报"找不到消息包" | 依赖包没先编译 | 先编消息包 |
| 换终端就"失效" | 环境变量只对当前终端有效 | 每个新终端重新 source |
| 用了 sudo 后出问题 | root 和普通用户环境不同 | **不要用 sudo 编译/运行** |
