## 1. 构建与运行

```bash
colcon build                                      # 编译所有包
colcon build --packages-select campus_vision      # 只编一个
colcon build --packages-select tdt_interface campus_vision   # 编两个
colcon build --cmake-args -DCMAKE_BUILD_TYPE=Release   # Release 版（更快）

source install/setup.bash                         # 加载环境
ros2 run campus_vision campus_node                # 运行
ros2 run campus_vision campus_node --ros-args -p threshold:=150   # 带参数运行
```

| 命令 | 作用 |
| --- | --- |
| `colcon build` | 编译工作空间 |
| `--packages-select 包名` | 只编指定的包（快） |
| `--symlink-install` | 开发用，改 Python 不用重编 |
| `source install/setup.bash` | 让终端认识你的包 |
| `ros2 run 包 可执行` | 运行节点 |
| `Ctrl+C` | 停止（优雅退出） |

**查看编译日志：** `log/latest_build/包名/stdout_stderr.log`

## 2. 节点相关 node

```bash
ros2 node list                    # 列出所有运行中的节点
ros2 node info /campus_node       # 看某节点的订阅/发布/服务
```

`ros2 node info` 的输出最有信息量：

```
/campus_node
  Subscribers:
    /camera/image_raw/compressed: sensor_msgs/msg/CompressedImage
    /autoaim/frame: tdt_interface/msg/AutoAimFrame
  Publishers:
    /target_angles_player_1: tdt_interface/msg/SendData
  Service Servers:
  ...
```

**什么时候用：**

- 确认节点有没有起来 → `node list`
- 确认节点订阅/发布了啥 → `node info`

## 3. 话题相关 topic（最常用）

### 3.1 列出话题

```bash
ros2 topic list           # 所有话题
ros2 topic list -t        # 带类型
ros2 topic list -v        # 带类型和数量
```

### 3.2 看话题信息

```bash
ros2 topic info /autoaim/frame            # 发布者/订阅者数量
ros2 topic info /autoaim/frame -v         # 详细（含 QoS）
```

输出示例：

```
Type: tdt_interface/msg/AutoAimFrame
Publisher count: 1
Subscription count: 2
```

**什么时候用：**

- 发布者 0 → 没人发数据（游戏没启动/没进对局）。
- 订阅者 0 → 你的程序没订阅上（名字错了/没编译）。

### 3.3 看频率

```bash
ros2 topic hz /camera/image_raw/compressed
```

输出：

```
average rate: 58.82
    min: 0.015s max: 0.022s std dev: 0.0012s window: 59
```

**什么时候用：**

- 确认数据在不在发、频率多少。
- 判断"是不是太慢"（识别频率低可能因为 CPU 不够）。

### 3.4 看内容

```bash
ros2 topic echo /autoaim/state                    # 实时打印
ros2 topic echo /autoaim/state --once             # 只打一条
ros2 topic echo /autoaim/state --field yaw_degrees   # 只看某个字段
ros2 topic echo /camera/image_raw/compressed --no-arr   # 不打印大数组（图像必备）
```

**图像话题一定要加 `--no-arr`**，否则终端会被几万个数刷爆。

**什么时候用：** 想亲眼确认消息内容对不对（字段有没有值、时间戳是否更新）。

### 3.5 手动发消息

```bash
ros2 topic pub /topic名 类型 "{字段: 值}"           # 发一次
ros2 topic pub -r 10 /topic名 类型 "{字段: 值}"     # 10Hz 连续发
```

例子：

```bash
ros2 topic pub /target_speed_player_1 geometry_msgs/msg/TwistStamped \
  "{twist: {linear: {x: 0.0}, angular: {z: 0.0}}}"
```

**什么时候用：** 测试自己的订阅端（不用等真正的发布方）。

### 3.6 看带宽

```bash
ros2 topic bw /camera/image_raw/compressed
```

**什么时候用：** 网络/性能问题排查（图像太大？）。

## 4. 消息接口 interface

```bash
ros2 interface list                              # 所有可用消息类型
ros2 interface show sensor_msgs/msg/CompressedImage   # 看某类型的字段
ros2 interface show tdt_interface/msg/AutoAimFrame
ros2 interface proto tdt_interface/msg/SendData  # 生成模板
```

输出示例：

```
std_msgs/Header header
uint64 frame_sequence
geometry_msgs/Point position
...
```

**什么时候用：**

- 不记得消息有哪些字段 → `show`。
- 想知道话题的消息类型 → 配合 `topic list -t`。

## 5. 服务相关 service

```bash
ros2 service list                       # 列出服务
ros2 service list -t                    # 带类型
ros2 service type /服务名               # 看类型
ros2 service call /服务名 类型 "{参数}"
```

**什么时候用：** 项目里用到"请求-应答"时（校园赛项目主要用话题，服务少）。

## 6. 参数相关 param

```bash
ros2 param list                         # 列出某节点的参数
ros2 param list /campus_node
ros2 param get /campus_node threshold   # 读
ros2 param set /campus_node threshold 150   # 改（运行时）
ros2 param dump /campus_node            # 导出成 yaml
```

**什么时候用：** 参数调优（不用重编译）。

## 7. 数据记录 bag

**bag = 把话题数据录下来，以后重放。** 排查问题神器。

```bash
# 录（指定话题或全部）
ros2 bag record /camera/image_raw/compressed /autoaim/frame -o mybag

# 录所有
ros2 bag record -a

# 看信息
ros2 bag info mybag

# 重放
ros2 bag play mybag
ros2 bag play mybag -r 2       # 2 倍速
```

**什么时候用：**

- 现场没时间调，先录下来回去慢慢调。
- 给自己的识别程序做"离线测试"（重放 + 跑节点）。
- **注意：** 图像数据录起来很大，注意磁盘。

## 8. 启动文件 launch

`launch` 文件可以"一条命令启动多个节点"：

```python
# my_launch.py
from launch import LaunchDescription
from launch_ros.actions import Node

def generate_launch_description():
    return LaunchDescription([
        Node(package='campus_vision', executable='campus_node',
             name='campus_node', output='screen',
             parameters=[{'threshold': 150}]),
        Node(package='other_pkg', executable='other_node'),
    ])
```

```bash
ros2 launch 包名 my_launch.py
```

**什么时候用：** 项目变复杂、需要一起启动多个节点时。

## 9. 图形化工具

| 工具 | 作用 | 命令 |
| --- | --- | --- |
| `rqt` | 综合工具箱 | `rqt` |
| `rqt_graph` | 画节点/话题关系图 | `rqt_graph` |
| `rqt_plot` | 画数值曲线（调参神器） | `rqt_plot` |
| `rqt_console` | 看日志 | `rqt_console` |
| `rviz2` | 3D 可视化 | `rviz2` |

**rqt_graph 最有用：** 一眼看出"谁连谁"，能立刻发现"根本没连上"。

**rqt_plot 调参：**
```bash
rqt_plot /autoaim/state/yaw_degrees
```
可以看角度是怎么变化的（抖动？发散？）。

## 10. 系统诊断 doctor / wtf

```bash
ros2 doctor        # 体检：环境、网络、中间件
ros2 wtf           # why these failures：给出问题和建议
```

**什么时候用：** 一切都怪怪的（收不到消息、环境混乱）时先跑一下。

## 11. 调试实战：常见问题怎么查

### 问题 1：收不到消息

**按顺序查：**

```bash
# 1. 话题存在吗？
ros2 topic list | grep autoaim

# 2. 有发布者吗？
ros2 topic info /autoaim/frame
# Publisher count 是 0 → 游戏没开/没进对局/桥没起来

# 3. 有数据吗？
ros2 topic hz /autoaim/frame
# 没频率 → 发布方没在发

# 4. 内容对吗？
ros2 topic echo /autoaim/frame --once

# 5. domain 一致吗？
echo $ROS_DOMAIN_ID
```

**常见原因排序：** 没进对局 > domain 不一致 > 话题名拼错 > QoS 不匹配 > 节点没起来。

### 问题 2：程序在跑但没输出

```bash
ros2 node list                 # 节点在吗
ros2 node info /你的节点        # 订阅列表对吗
ros2 topic hz /你订阅的话题     # 上游有数据吗
```

再检查代码：回调里第一行加打印 `"进入回调"`。

### 问题 3：识别结果不对

```bash
# 看输入数据是否正常
ros2 topic hz /camera/image_raw/compressed      # 频率正常吗
ros2 topic echo /autoaim/state --field yaw_degrees   # 状态在变吗
```

程序里：把中间结果 `imshow` / `imwrite` 出来看（见 OpenCV 篇）。

### 问题 4：发布出去的东西没反应

```bash
ros2 topic info /target_angles_player_1 -v     # 有人订阅吗
ros2 topic echo /target_angles_player_1        # 有数据吗
ros2 topic hz /target_angles_player_1          # 频率多少
```

如果发布者/订阅者数量不对 → 话题名写错（比如 `_1` 写成 `_2`）。

### 问题 5：编译/运行怪问题

```bash
# 看编译日志
cat log/latest_build/包名/stdout_stderr.log

# 清干净重编（最后手段）
rm -rf build/ install/ log/
colcon build
```

### 问题 6：性能/延迟问题

```bash
ros2 topic hz /camera/image_raw/compressed      # 上游频率
ros2 topic bw /camera/image_raw/compressed      # 带宽
top                                             # CPU 占用（看你的节点）
```

程序里用计时打印找出慢的一步。
