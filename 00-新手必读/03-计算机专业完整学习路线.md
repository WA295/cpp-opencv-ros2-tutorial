## 1. 全景图:计算机专业到底学什么

把计算机专业的所有内容分层,像盖楼一样:

```
┌────────────────────────────────────────────────┐
│  ⑥ 工程与协作层:Git / Linux / 调试 / 文档 / 英语 │ ← 每天都要用
├────────────────────────────────────────────────┤
│  ⑤ 方向技能层(选修,挑 1~2 个)                    │
│     后端 │ 前端 │ 客户端 │ AI │ 嵌入式 │ 游戏 │ 安全 │
├────────────────────────────────────────────────┤
│  ④ 应用层:数据库、Web、网络编程、并发、API 设计    │ ← 做产品必备
├────────────────────────────────────────────────┤
│  ③ 专业基础(四大件,计算机的"内功")               │
│     数据结构与算法 │ 计算机组成 │ 操作系统 │ 计算机网络 │
├────────────────────────────────────────────────┤
│  ② 数学地基:高数、线性代数、概率论、离散数学       │
├────────────────────────────────────────────────┤
│  ① 编程语言:先把 C++ 或 Python 学透一门           │
└────────────────────────────────────────────────┘
```

**重要认知**:上面的楼,越往下越"通用、保值",越往上越"具体、好变现"。
- 只学上面不学下面 → 会调库的"码农",遇到底层问题就卡死
- 只学下面不学上面 → 会原理但做不出产品,找不到成就感
- 正确姿势:**地基 + 一门手艺**,比如「算法内功 + 后端手艺」或「数学内功 + AI 手艺」

本仓库的 C++ / OpenCV / ROS2 主线,本质上是「**嵌入式 + AI(视觉)**」方向的一套完整手艺。这份文档的作用是补上全景:知道还有哪些东西、每条路通向哪里、各种项目需要哪些知识。

## 2. 必修核心(所有方向的地基)

### 2.1 编程语言:先学透一门

| 语言 | 学什么 | 适合方向 | 备注 |
|------|--------|----------|------|
| **C++** | 语法 → 指针/内存 → 类与对象 → 模板 → STL → 智能指针 | 嵌入式/机器人/游戏/底层/高频交易 | 本仓库 01- 系列 |
| **Python** | 语法 → 数据结构 → 函数式 → 类 → 标准库 | AI/脚本/爬虫/自动化/后端 | 上手最快 |
| **C** | 指针/内存/结构体(理解计算机的捷径) | 操作系统/嵌入式/逆向 | 学 C++ 已覆盖大半 |
| **JavaScript** | ES6 → 异步(promise/await)→ Node.js | Web 前后端/小程序/桌面(Electron) | Web 方向必学 |

**学到什么程度算"会"**:不看资料能写出 300 行以内的小程序(比如:读文件统计单词、写个计算器、发 HTTP 请求存数据)。

### 2.2 数据结构与算法(最重要的一门,没有之一)

- **学什么**:数组/链表/栈/队列/哈希表/树(二叉、堆、平衡树)/图;排序/查找/递归/动态规划/贪心/BFS/DFS
- **为什么重要**:面试必考;决定代码能不能"扛住大规模数据";是所有 AI、编译、图形学的底座
- **学完能做什么**:LeetCode 中等题独立解决;看懂任何开源库的核心逻辑
- **实际应用举例**:消息系统里的"队列"、路径规划里的"图搜索"(A*)、图像处理里的"二维数组遍历优化"
- **资源**:代码随想录(免费)、LeetCode(每天 1~2 题)、《算法导论》(教科书,选读)
- **建议时间**:2~3 个月,边学边刷题,别只看书

### 2.3 计算机组成原理(理解"程序怎么在机器上跑")

- **学什么**:二进制、CPU 怎么执行指令、内存/缓存、存储、总线
- **为什么重要**:解释了所有性能问题和玄学 bug 的根源
- **学完能做什么**:看懂「为什么程序慢/崩/内存暴涨」;嵌入式方向的基础
- **资源**:王道考研《计算机组成原理》(B 站免费)、CSAPP《深入理解计算机系统》(神书,挑前几章读)
- **建议时间**:3~4 周了解即可,不必深究数字电路

### 2.4 操作系统(理解"程序怎么被管理")

- **学什么**:进程/线程、内存管理、文件系统、调度、死锁、并发同步
- **为什么重要**:多线程程序、服务器、嵌入式(RTOS)都离不开;面试必考
- **学完能做什么**:写出正确高效的多线程程序;看懂「为什么卡死/竞争/泄漏」
- **实际应用举例**:机器人系统里的节点/进程、回调/线程;服务端程序同时处理多个连接
- **资源**:王道考研《操作系统》(B 站免费)、《现代操作系统》(选读)、MIT 6.S081(硬核进阶)
- **建议时间**:1~2 个月

### 2.5 计算机网络(理解"程序之间怎么通信")

- **学什么**:TCP/IP、HTTP、WebSocket、DNS、端口、防火墙、抓包
- **为什么重要**:现在几乎没有不联网的软件;后端/全栈/运维/安全的命根子
- **学完能做什么**:自己写聊天程序、看懂任何 API 文档、排网络故障
- **实际应用举例**:聊天机器人 = HTTP + WebSocket;机器人通信协议(如 DDS)也是网络协议
- **资源**:王道考研《计算机网络》、小林 coding《图解网络》(免费,强烈推荐)
- **建议时间**:1 个月

### 2.6 数据库(理解"数据怎么存和查")

- **学什么**:SQL、表设计、索引、事务、Redis(缓存)
- **为什么重要**:几乎所有后端都离不开;面试常考
- **学完能做什么**:给任何应用设计数据表;优化慢查询
- **实际应用举例**:任何"记录数据"的软件(待办、账本、聊天记录)都要建表+增删改查
- **资源**:SQL 教程(菜鸟/廖雪峰,免费)、《MySQL 必知必会》
- **建议时间**:2~3 周(入门 SQL 很快,深入优化以后再说)

### 2.7 数学地基

| 科目 | 用在哪 | 学到什么程度 |
|------|--------|--------------|
| 高等数学 | 一切算法的数学语言 | 必修课认真学,微积分基础 |
| 线性代数 | 机器学习/图形学/机器人 | **重点**(相机模型、坐标变换全是矩阵) |
| 概率论与统计 | AI/数据分析 | 重点,懂分布/期望/贝叶斯 |
| 离散数学 | 算法/密码学 | 了解图论、数理逻辑即可 |

> 数学的「用在哪」在做项目时会有切身体会:机器人视觉 = 线性代数的应用,AI = 概率统计的应用。

## 3. 选修方向(按兴趣挑 1~2 个深挖)

| 方向 | 核心内容 | 需要的地基 | 就业/应用 | 入门资源 |
|------|----------|-----------|-----------|----------|
| **后端开发** ⭐最通用 | 语言(Python/Java/Go/Node)+ 框架 + 数据库 + 部署 | 网络+数据库 | 岗位最多,什么公司都要 | 廖雪峰 Python、bilibili 项目课 |
| **前端开发** | HTML/CSS/JS → Vue/React | 几乎只要 JS | 岗位多,作品看得见 | MDN、阮一峰 ES6、Vue 官方教程 |
| **桌面/客户端** | Electron(JS)/ Qt(C++) | 前端或 C++ | 工具软件、工业软件 | Electron 官方文档、Qt 官方教程 |
| **AI/机器学习** | 数学 → 机器学习 → 深度学习(PyTorch)→ LLM 应用 | 线代+概率+Python | 风口方向,卷但机会多 | 吴恩达机器学习(B站免费)、李沐《动手学深度学习》(免费) |
| **嵌入式/机器人** ⭐工程味最浓 | C/C++、单片机、ROS、传感器、电机 | C++、组成原理 | 硬件公司、机器人公司 | 本仓库 + 野火/正点原子教程 |
| **游戏开发** | C#+Unity 或 C+++Unreal | 数学+C++ | 游戏公司 | Unity 官方教程(免费) |
| **网络安全** | 渗透、逆向、密码学 | 网络+系统+组成 | 安全公司、CTF 竞赛 | CTF wiki(免费)、B 站入门 |
| **系统底层** | 内核、驱动、高性能 C/C++/Rust | 操作系统+组成 | 大厂基础架构、芯片公司 | CSAPP、MIT 6.S081 |
| **运维/DevOps** | Linux、Docker、K8s、CI/CD | 网络+系统 | 云厂商、互联网公司 | Docker 官方教程 |
| **数据科学** | Python、Pandas、可视化、统计 | 概率+Python | 数据分析师 | Kaggle、和鲸社区 |

**常见组合建议**:
- 想就业面最宽 → 后端 + 前端基础(全栈)
- 想卷 AI/读研 → 机器学习 + 数学(线代概率学扎实)
- 想走硬件/机器人 → 嵌入式 + 视觉(本仓库主线)
- 想独立做产品 → 后端/前端 + 一点点产品思维

### 5.2 典型项目拆解:一个"消息转待办"机器人

> 以开源项目 [msg2todo](https://github.com/WA295/msg2todo)(QQ 消息自动生成待办 + 桌面看板 + 手机推送)为例:

```
功能点                    需要的知识                      难度
─────────────────────────────────────────────────────────
接收聊天消息           WebSocket 协议、机器人协议规范      ★★☆
                      (网络课 + 读协议文档)
判断"是不是待办"       LLM API 调用 / 自己写规则          ★★☆
                      (HTTP 请求 + prompt 设计)
存待办                 SQLite/MySQL,建表+增删改查        ★☆☆
                      (数据库课 2 周就能会)
网页看板               HTML/CSS/JS + HTTP 接口           ★★☆
                      (前端基础 + 后端给接口)
桌面软件               Electron(JS 套壳)                 ★☆☆
                      (看懂官方文档即可)
手机推送               第三方推送服务的 HTTP 接口         ★☆☆
                      (还是 HTTP,没新东西)
开机自启/部署          Linux 进程管理、systemd/autostart  ★★☆
                      (操作系统课的实践应用)
─────────────────────────────────────────────────────────
真正的难点:① 没有官方 API 的平台逆向(工程经验,不是知识)
           ② 跨平台打包踩坑(遇到再查)
```

**结论**:去掉"踩坑"部分,做这样一个软件所需的**课本知识** = 网络 + 数据库 + 前端基础 + 一点操作系统常识。学完第 2 章的四大件 + 一门语言,就具备了做出类似软件的知识储备。

## 6. 大学四年时间轴(参考规划)

> 以「大一有编程课、大二有比赛/项目」的常见进度为例;起点不同按第 8 章调整。

| 阶段 | 主线 | 副线 | 产出 |
|------|------|------|------|
| **大一** | 学透一门语言(C++/Python)+ 数学课 | 接触 Git、GitHub、Linux | 能写 300 行小程序 |
| **大二上** | 数据结构与算法(开始刷题)+ 组成/OS | 选一个方向(第 3 章) | 算法题 100+ |
| **大二下** | 网络 + 数据库 + 方向入门 | 做一个完整项目 | 一个能写进简历的项目 |
| **暑假** | 独立复刻/原创一个完整项目 | 整理 GitHub、写简历 | **「能独立做软件」达成** |
| **大三** | 方向深挖 + 找实习 | 参加开源/比赛 | 实习 offer |
| **大四** | 实习转正/考研/秋招 | 毕业论文 | 去向确定 |

**核心节奏:一年一个台阶**
- 第一年:学完地基 + 能独立做小项目
- 第二年:方向深挖 + 实习
- 第三年:拿 offer 或读研

## 8. 不同起点,怎么用这份文档

### 零基础新生(刚接触编程)
1. 学一门语言(C++ 看本仓库 01- 系列;Python 看廖雪峰)
2. 大一下开始数据结构与算法 + LeetCode
3. 每个学期末做一个第 5 章里的小项目(博客 → 爬虫 → 机器人)
4. 大二再按第 6 章时间轴对齐

### 有 C++ 基础,方向未定
1. 补数据结构与算法(最优先)+ 操作系统
2. 用 1~2 个月快速过网络 + 数据库(入门很快)
3. 挑第 3 章一个方向 + 做一个对应项目(第 5 章有拆解)

### 机器人/嵌入式路线(本仓库主线)
1. 按本仓库 01→06 顺序继续
2. 同步补:数据结构与算法(路径规划要用)、操作系统(RTOS/并发)
3. 第二方向建议「AI」(与视觉衔接)或「后端」(能独立做产品)

### 想转软件/互联网方向
1. 语言补 JavaScript 或 Java
2. 网络 + 数据库 + 一个后端/前端框架
3. 用第 5 章的项目对照表做 2~3 个项目进简历
4. 刷 LeetCode(面试硬门槛)

### 通用检验标准(什么时候算入门/出师)
- **入门**:独立完成第 5 章里任意 2 个项目
- **出师**:拿到一个需求(比如"做一个课表提醒机器人")能自己完成「拆解 → 选技术 → 实现 → 部署」全流程
- 按第 6 章的节奏,**每天 2 小时,大约 6~12 个月**能从零达到"能独立做出一个完整软件"的水平
