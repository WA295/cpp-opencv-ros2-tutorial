## 1. 全景图:计算机专业到底学什么

把计算机专业的所有内容分层,像盖楼一样:

```
┌────────────────────────────────────────────────┐
│  ⑥ 工程与协作层:Git / Linux / 调试 / 文档 / 英语 │ ← 每天都要用
├────────────────────────────────────────────────┤
│  ⑤ 方向技能层(选修,挑 1~2 个)                    │
│     后端 │ 前端 │ 客户端 │ AI │ 嵌入式 │ 游戏 │ 安全 │
├────────────────────────────────────────────────┤
│  ④ 应用层:数据库、Web、网络编程、并发、API 设计    │ ← 做产品必备
├────────────────────────────────────────────────┤
│  ③ 专业基础(四大件,计算机的"内功")               │
│     数据结构与算法 │ 计算机组成 │ 操作系统 │ 计算机网络 │
├────────────────────────────────────────────────┤
│  ② 数学地基:高数、线性代数、概率论、离散数学       │
├────────────────────────────────────────────────┤
│  ① 编程语言:先把 C++ 或 Python 学透一门           │ ← 你已经有了
└────────────────────────────────────────────────┘
```

**重要认知**:上面的楼,越往下越"通用、保值",越往上越"具体、好变现"。
- 只学上面不学下面 → 会调库的"码农",遇到底层问题就卡死
- 只学下面不学上面 → 会原理但做不出产品,找不到成就感
- 正确姿势:**地基 + 一门手艺**,比如「算法内功 + 后端手艺」或「数学内功 + AI 手艺」

你的机器人路线(C++/OpenCV/ROS2)本质上是「**嵌入式 + AI(视觉)方向**」,它已经是一套完整的手艺了——本仓库前 6 个目录就是这条线。这份文档帮你补上全景,知道还有哪些东西、每条路通向哪里。

## 2. 必修核心(所有方向的地基)

### 2.1 编程语言:先学透一门

| 语言 | 学什么 | 适合方向 | 你已会 |
|------|--------|----------|--------|
| **C++** | 语法 → 指针/内存 → 类与对象 → 模板 → STL → 智能指针 | 嵌入式/机器人/游戏/底层/高频交易 | ✅ 本仓库 01- 系列 |
| **Python** | 语法 → 数据结构 → 函数式 → 类 → 标准库 | AI/脚本/爬虫/自动化/后端 | 🟡 会用一点 |
| **C** | 指针/内存/结构体(理解计算机的捷径) | 操作系统/嵌入式/逆向 | 🟡 C++ 已覆盖大半 |
| **JavaScript** | ES6 → 异步(promise/await)→ Node.js | Web 前后端/小程序/桌面(Electron) | ❌ 做 msg2todo 时补的 |

**学到什么程度算"会"**:不看资料能写出 300 行以内的小程序(比如:读文件统计单词、写个计算器、发 HTTP 请求存数据)。

### 2.2 数据结构与算法(最重要的一门,没有之一)

- **学什么**:数组/链表/栈/队列/哈希表/树(二叉、堆、平衡树)/图;排序/查找/递归/动态规划/贪心/BFS/DFS
- **为什么重要**:面试必考;决定你代码能不能"扛住大规模数据";是所有 AI、编译、图形学的底座
- **学完能做什么**:LeetCode 中等题独立解决;看懂任何开源库的核心逻辑
- **与你的项目联系**:ROS2 的消息队列是"队列";路径规划是"图搜索"(A*);OpenCV 里到处都是"二维数组+遍历优化"
- **资源**:代码随想录(免费,网站/公众号)、LeetCode(每天 1~2 题)、《算法导论》(教科书,选读)
- **建议时间**:2~3 个月,边学边刷题,别只看书

### 2.3 计算机组成原理(理解"程序怎么在机器上跑")

- **学什么**:二进制、CPU 怎么执行指令、内存/缓存、存储、总线
- **为什么重要**:解释了所有性能问题和玄学 bug 的根源
- **学完能做什么**:看懂「为什么我的程序慢/崩/内存暴涨」;嵌入式基础
- **资源**:王道考研《计算机组成原理》(免费 B 站课)、CSAPP《深入理解计算机系统》(神书,挑前几章读)
- **建议时间**:3~4 周了解即可,不必深究数字电路

### 2.4 操作系统(理解"程序怎么被管理")

- **学什么**:进程/线程、内存管理、文件系统、调度、死锁、并发同步
- **为什么重要**:多线程程序、服务器、嵌入式(RTOS)都离不开;面试必考
- **学完能做什么**:写出正确高效的多线程程序;看懂「为什么卡死/竞争/泄漏」
- **与你的项目联系**:ROS2 的节点就是进程、回调就是线程;msg2todo 里同时跑 QQ 连接+看板+LLM 就是并发
- **资源**:王道考研《操作系统》(B 站免费)、《现代操作系统》(选读)、MIT 6.S081(硬核进阶)
- **建议时间**:1~2 个月

### 2.5 计算机网络(理解"程序之间怎么通信")

- **学什么**:TCP/IP、HTTP、WebSocket、DNS、端口、防火墙、抓包
- **为什么重要**:现在几乎没有不联网的软件;后端/全栈/运维/安全的命根子
- **学完能做什么**:自己写聊天程序、看懂任何 API 文档、排网络故障
- **与你的项目联系**:msg2todo 的核心就是 HTTP + WebSocket + 反向代理;ROS2 的 DDS 也是网络协议
- **资源**:王道考研《计算机网络》、小林 coding(图解网络,神作,免费)
- **建议时间**:1 个月

### 2.6 数据库(理解"数据怎么存和查")

- **学什么**:SQL、表设计、索引、事务、Redis(缓存)
- **为什么重要**:几乎所有后端都离不开;面试常考
- **学完能做什么**:给任何应用设计数据表;优化慢查询
- **与你的项目联系**:msg2todo 用 SQLite 存待办,`SELECT/INSERT/UPDATE` 每天发生
- **资源**:SQL 教程(菜鸟/廖雪峰,免费)、MySQL 必知必会
- **建议时间**:2~3 周(入门 SQL 很快,深入优化以后再说)

### 2.7 数学地基

| 科目 | 用在哪 | 学到什么程度 |
|------|--------|--------------|
| 高等数学 | 一切算法的数学语言 | 必修课认真学,微积分基础 |
| 线性代数 | 机器学习/图形学/机器人 | **重点**(你在做的相机模型 PnP 全是矩阵) |
| 概率论与统计 | AI/数据分析 | 重点,懂分布/期望/贝叶斯 |
| 离散数学 | 算法/密码学 | 了解图论、数理逻辑即可 |

> 你已经在做 OpenCV/ROS2 项目,数学的「用在哪」你应该有切身体会——机器人视觉 = 线性代数的应用。

## 3. 选修方向(按兴趣挑 1~2 个深挖)

| 方向 | 核心内容 | 需要的地基 | 就业/应用 | 入门资源 |
|------|----------|-----------|-----------|----------|
| **后端开发** ⭐最通用 | 语言(Python/Java/Go/Node)+ 框架 + 数据库 + 部署 | 网络+数据库 | 岗位最多,什么公司都要 | 廖雪峰 Python、bilibili 项目课 |
| **前端开发** | HTML/CSS/JS → Vue/React | 几乎只要 JS | 岗位多,作品看得见 | MDN、阮一峰 ES6、Vue 官方教程 |
| **桌面/客户端** | Electron(JS)/ Qt(C++) | 前端或 C++ | 工具软件、工业软件 | Electron 官方文档、Qt 官方教程 |
| **AI/机器学习** | 数学 → 机器学习 → 深度学习(PyTorch)→ LLM 应用 | 线代+概率+Python | 风口方向,卷但机会多 | 吴恩达机器学习(B站免费)、李沐《动手学深度学习》(免费) |
| **嵌入式/机器人** ⭐你已在这 | C/C++、单片机、ROS、传感器、电机 | C++、组成原理 | 硬件公司、机器人公司 | 本仓库 + 野火/正点原子教程 |
| **游戏开发** | C#+Unity 或 C+++Unreal | 数学+C++ | 游戏公司 | Unity 官方教程(免费) |
| **网络安全** | 渗透、逆向、密码学 | 网络+系统+组成 | 安全公司、CTF 竞赛 | CTF wiki(免费)、B 站入门 |
| **系统底层** | 内核、驱动、高性能 C/C++/Rust | 操作系统+组成 | 大厂基础架构、芯片公司 | CSAPP、MIT 6.S081 |
| **运维/DevOps** | Linux、Docker、K8s、CI/CD | 网络+系统 | 云厂商、互联网公司 | Docker 官方教程 |
| **数据科学** | Python、Pandas、可视化、统计 | 概率+Python | 数据分析师 | Kaggle、和鲸社区 |

**给你的选择建议**:你的主线已经是「嵌入式+机器人视觉」,这非常扎实。建议**第二方向选后端或 AI**:
- 选后端 → 以后能独立做完整产品(像 msg2todo 这样的工具),就业面最宽
- 选 AI → 和你机器人视觉无缝衔接,比赛/读研都吃香

### 5.2 典型项目拆解(以你熟悉的 msg2todo 为例)

**目标:QQ 消息自动生成待办 + 手机推送**

```
功能点                    需要的知识                      难度
─────────────────────────────────────────────────────────
接收 QQ 消息         WebSocket 协议、OneBot 规范          ★★☆
                      (网络课 + 看协议文档)
判断"是不是待办"     LLM API 调用 / 写规则               ★★☆
                      (HTTP 请求 + prompt 设计)
存待办               SQLite/MySQL,建表+增删改查         ★☆☆
                      (数据库课 2 周就能会)
网页看板             HTML/CSS/JS + HTTP 接口            ★★☆
                      (前端基础 + 后端给接口)
桌面软件             Electron(JS 套壳)                  ★☆☆
                      (看懂官方文档即可)
手机推送             Bark/PushDeer 的 HTTP 接口          ★☆☆
                      (还是 HTTP,没新东西)
开机自启/部署        Linux 进程管理、systemd/autostart   ★★☆
                      (操作系统课的实践应用)
─────────────────────────────────────────────────────────
真正的难点:① 微信这种"没有官方 API"的逆向(工程经验,不是知识)
           ② 跨平台打包踩坑(遇到再查)
```

**结论**:去掉那些"踩坑"部分,做这样一个软件所需的**课本知识** = 网络 + 数据库 + 前端基础 + 一点操作系统常识。你按第 2 章补完这些,就具备了独立做出类似软件的知识储备。

## 6. 学生四年时间轴(建议规划)

> 以你现在的位置(已有 C++/OpenCV/ROS2 + 校园赛经验,大概大二)为起点:

| 阶段 | 主线 | 副线 | 产出 |
|------|------|------|------|
| **现在 ~ 本学期末** | 校园赛项目收尾 + 补网络/数据库课 | LeetCode 每天 1 题 | 比赛成绩 + 可写的简历项目 |
| **寒假(1 个月)** | JS + 前端基础 | 改造 msg2todo(改界面/加功能) | 一个自己动手改过的软件 |
| **下学期** | 数据结构与算法系统学 + 操作系统 | 选第二方向(后端或 AI)入门 | 算法题 200+、一个小后端 |
| **暑假(2 个月)** | 独立复刻一个完整项目 | 整理 GitHub、写简历 | **「我能独立做软件」达成** |
| **大三** | 深挖方向(后端框架/AI 或机器人)+ 找实习 | 参加开源/比赛 | 实习 offer |
| **大四** | 实习转正/考研/秋招 | 毕业论文 | 去向确定 |

**核心节奏:一年一个台阶**
- 第一年:补完地基 + 能独立做小项目
- 第二年:方向深挖 + 实习
- 第三年:拿 offer 或读研

## 8. 给你的专属建议(结合你的现状)

### 你现在的资产(很多人没有的)
- ✅ C++ 实打实的项目经验(不是玩具代码)
- ✅ OpenCV + ROS2 的机器人视觉能力
- ✅ 真实的比赛项目(校园赛)
- ✅ 有 GitHub 习惯、有笔记仓库、有完整软件作品(msg2todo)

### 你现在缺的(按优先级排)
1. **数据结构与算法**(面试硬通货,越早越好)
2. **计算机网络 + 数据库**(做产品的地基,msg2todo 里已经天天在用,学起来会非常快——你有真实场景)
3. **JavaScript/Web 基础**(第二手艺,拓宽能做的产品类型)
4. **操作系统常识**(并发/进程/部署,用到再深挖)

### 我的具体建议

**近期(1~3 个月)**:
- 每天 1~2 题 LeetCode(先做简单题,配代码随想录)
- 通读一遍小林 coding《图解网络》,遇到 msg2todo 里出现过的名词(WebSocket、反向代理、端口)重点看
- 每周花 2 小时"玩" msg2todo 源码:改一个功能、加一个配置项、换个界面颜色

**中期(3~12 个月)**:
- 系统过一遍数据结构与算法 + 操作系统
- 确定第二方向(我推荐「后端」或「AI」,第 3 章有对照)
- 独立复刻一个简化版 msg2todo(不看原代码,卡住再看)

**检验标准(什么时候算"出师")**:
- 算法:LeetCode 中等题 30 分钟内独立解出
- 工程:拿到一个需求(比如"做一个课表提醒机器人")能自己拆解 → 选技术 → 实现 → 部署
- 到那时,你问的「什么时候能独立做出这个软件」就自动有了答案:**大约 6~12 个月,视投入而定**;而你现在已经是这条路上起步很早的人。
