# 练手 3：综合 —— 迷你视觉瞄准项目

> 这是练手系列的**毕业项目**：把 C++、OpenCV、ROS 2 串起来，
> 做一个完整但**简化版**的"视觉瞄准"节点：
> 订阅图像 → 找到红色目标 → 算出它相对画面中心的偏角 → 发布瞄准指令。
> 它和校园赛项目的骨架一模一样，只是算法做了最大简化，方便你一次跑通、彻底看懂。

## 1. 项目设计：输入输出

**先写清楚"合同"，再写代码：**

| 项目 | 内容 |
| --- | --- |
| 输入 | `/camera/image_raw/compressed`（压缩图像） |
| 输出 | `/aim_offset`（`std_msgs/String`：目标偏离中心的像素和估算角度） |
| 目标 | 画面里的**红色物体** |
| 假设 | 相机中心大致对准前方，用"像素偏移 ÷ 焦距"近似角度（小角度） |

> 真实项目会收到相机内参并做 PnP；这里为了"快速上手"先用最简单近似，
> 升级路径在最后一节。

## 2. 整体流程图

```
图像进来（imageCallback）
   │
   ├─ 降频：每 3 帧处理 1 帧
   │
   ├─ 转 HSV → inRange 找红色
   ├─ 形态学开运算去噪
   ├─ findContours 找红色块
   ├─ 取面积最大的那个（目标）
   ├─ 算它的重心 (cx, cy)
   │
   ├─ 和画面中心 (w/2, h/2) 比较
   │    dx = cx - w/2,  dy = cy - h/2
   │
   ├─ 用近似公式换算角度：
   │    yaw   ≈ dx / fx
   │    pitch ≈ dy / fy
   │
   └─ 发布到 /aim_offset（并画框显示）
```

## 3. 分步实现

### 第 1 步：先把图像收下来显示（验证通信）

```cpp
void onImage(const sensor_msgs::msg::CompressedImage::SharedPtr msg)
{
    cv::Mat img = cv::imdecode(msg->data, cv::IMREAD_COLOR);
    if (img.empty()) return;

    cv::imshow("raw", img);
    cv::waitKey(1);
}
```

**跑通这一步再往下！** 收不到图，后面全白搭。

### 第 2 步：找红色（HSV + inRange）

```cpp
cv::Mat hsv, mask1, mask2, mask;
cv::cvtColor(img, hsv, cv::COLOR_BGR2HSV);

// 红色在 HSV 中跨 0°，要两段再合并
cv::inRange(hsv, cv::Scalar(0, 100, 100),  cv::Scalar(10, 255, 255), mask1);
cv::inRange(hsv, cv::Scalar(170, 100, 100), cv::Scalar(180, 255, 255), mask2);
cv::bitwise_or(mask1, mask2, mask);

cv::imshow("mask", mask);   // 红色区域应该变白
```

### 第 3 步：去噪 + 找最大轮廓

```cpp
// 形态学开运算：去掉小白点
cv::Mat kernel = cv::getStructuringElement(cv::MORPH_RECT, cv::Size(5, 5));
cv::morphologyEx(mask, mask, cv::MORPH_OPEN, kernel);

std::vector<std::vector<cv::Point>> contours;
cv::findContours(mask, contours, cv::RETR_EXTERNAL, cv::CHAIN_APPROX_SIMPLE);

// 找面积最大的轮廓
double best_area = 0;
std::vector<cv::Point> best_contour;
for (const auto& c : contours) {
    double a = cv::contourArea(c);
    if (a > best_area) { best_area = a; best_contour = c; }
}
if (best_contour.empty()) return;    // 没找到目标
```

### 第 4 步：算重心和偏移

```cpp
cv::Moments m = cv::moments(best_contour);
double cx = m.m10 / m.m00;
double cy = m.m01 / m.m00;

double dx = cx - img.cols / 2.0;     // 右为正
double dy = cy - img.rows / 2.0;     // 下为正
```

### 第 5 步：像素偏移 → 角度

```cpp
// 焦距 fx、fy 用参数（单位：像素）。真实相机从 camera_info 拿。
// 小角度近似：tan(θ) ≈ θ，θ = 偏移 / 焦距
double yaw_rad   = dx / fx_;
double pitch_rad = dy / fy_;

double yaw_deg   = yaw_rad   * 180.0 / M_PI;
double pitch_deg = pitch_rad * 180.0 / M_PI;
```

### 第 6 步：发布 + 显示

```cpp
std_msgs::msg::String out;
out.data = "dx=" + std::to_string((int)dx) +
           " dy=" + std::to_string((int)dy) +
           " yaw=" + std::to_string(yaw_deg) +
           " pitch=" + std::to_string(pitch_deg);
pub_->publish(out);
```

## 4. 完整代码（一个文件）

`mini_aim/src/mini_aim.cpp`：

```cpp
#include <rclcpp/rclcpp.hpp>
#include <sensor_msgs/msg/compressed_image.hpp>
#include <std_msgs/msg/string.hpp>
#include <opencv2/opencv.hpp>

class MiniAimNode : public rclcpp::Node
{
public:
    MiniAimNode() : Node("mini_aim_node")
    {
        // 焦距参数（像素），默认 600；有真实内参可改成从话题接收
        this->declare_parameter("fx", 600.0);
        this->declare_parameter("fy", 600.0);
        fx_ = this->get_parameter("fx").as_double();
        fy_ = this->get_parameter("fy").as_double();

        sub_ = this->create_subscription<sensor_msgs::msg::CompressedImage>(
            "/camera/image_raw/compressed", 1,
            std::bind(&MiniAimNode::onImage, this, std::placeholders::_1));

        pub_ = this->create_publisher<std_msgs::msg::String>("/aim_offset", 10);

        RCLCPP_INFO(this->get_logger(), "mini_aim 启动，等待图像……");
    }

private:
    void onImage(const sensor_msgs::msg::CompressedImage::SharedPtr msg)
    {
        // 0. 降频：每 3 帧处理 1 帧
        static int frame_count = 0;
        if (++frame_count % 3 != 0) return;

        // 1. 解码
        cv::Mat img = cv::imdecode(msg->data, cv::IMREAD_COLOR);
        if (img.empty()) {
            RCLCPP_WARN_THROTTLE(this->get_logger(), *this->get_clock(), 5000,
                                 "解码失败");
            return;
        }

        // 2. 找红色（HSV 两段 + 合并）
        cv::Mat hsv, mask1, mask2, mask;
        cv::cvtColor(img, hsv, cv::COLOR_BGR2HSV);
        cv::inRange(hsv, cv::Scalar(0, 100, 100),   cv::Scalar(10, 255, 255), mask1);
        cv::inRange(hsv, cv::Scalar(170, 100, 100), cv::Scalar(180, 255, 255), mask2);
        cv::bitwise_or(mask1, mask2, mask);

        // 3. 去噪
        cv::Mat kernel = cv::getStructuringElement(cv::MORPH_RECT, cv::Size(5, 5));
        cv::morphologyEx(mask, mask, cv::MORPH_OPEN, kernel);

        // 4. 找最大红色块
        std::vector<std::vector<cv::Point>> contours;
        cv::findContours(mask, contours, cv::RETR_EXTERNAL, cv::CHAIN_APPROX_SIMPLE);

        double best_area = 0;
        std::vector<cv::Point> best_contour;
        for (const auto& c : contours) {
            double a = cv::contourArea(c);
            if (a > best_area) { best_area = a; best_contour = c; }
        }

        if (best_contour.empty()) {
            RCLCPP_INFO_THROTTLE(this->get_logger(), *this->get_clock(), 2000,
                                 "没有找到目标");
            return;
        }

        // 5. 重心 + 偏移
        cv::Moments m = cv::moments(best_contour);
        double cx = m.m10 / m.m00;
        double cy = m.m01 / m.m00;
        double dx = cx - img.cols / 2.0;
        double dy = cy - img.rows / 2.0;

        // 6. 像素偏移 → 角度（小角度近似）
        double yaw_deg   = (dx / fx_) * 180.0 / M_PI;
        double pitch_deg = (dy / fy_) * 180.0 / M_PI;

        // 7. 发布
        std_msgs::msg::String out;
        out.data = "dx=" + std::to_string((int)dx) +
                   " dy=" + std::to_string((int)dy) +
                   " yaw=" + std::to_string(yaw_deg) +
                   " pitch=" + std::to_string(pitch_deg);
        pub_->publish(out);

        // 8. 可视化
        cv::Rect box = cv::boundingRect(best_contour);
        cv::rectangle(img, box, cv::Scalar(0, 255, 0), 2);
        cv::circle(img, cv::Point((int)cx, (int)cy), 5, cv::Scalar(0, 0, 255), -1);
        // 画十字准心
        cv::line(img, cv::Point(img.cols/2 - 10, img.rows/2),
                 cv::Point(img.cols/2 + 10, img.rows/2), cv::Scalar(255, 255, 0), 1);
        cv::line(img, cv::Point(img.cols/2, img.rows/2 - 10),
                 cv::Point(img.cols/2, img.rows/2 + 10), cv::Scalar(255, 255, 0), 1);
        cv::putText(img, out.data, cv::Point(10, 30),
                    cv::FONT_HERSHEY_SIMPLEX, 0.7, cv::Scalar(0, 255, 255), 2);

        cv::imshow("mini_aim", img);
        cv::imshow("mask", mask);
        cv::waitKey(1);
    }

    double fx_, fy_;
    rclcpp::Subscription<sensor_msgs::msg::CompressedImage>::SharedPtr sub_;
    rclcpp::Publisher<std_msgs::msg::String>::SharedPtr pub_;
};

int main(int argc, char** argv)
{
    rclcpp::init(argc, argv);
    rclcpp::spin(std::make_shared<MiniAimNode>());
    rclcpp::shutdown();
    return 0;
}
```

## 5. 配套：假目标发布器

没有摄像头/游戏也能测 —— 发布一个"红球在动"的假图像：

```cpp
// fake_target/src/fake_target.cpp
#include <rclcpp/rclcpp.hpp>
#include <sensor_msgs/msg/compressed_image.hpp>
#include <opencv2/opencv.hpp>
#include <chrono>

using namespace std::chrono_literals;

class FakeTarget : public rclcpp::Node
{
public:
    FakeTarget() : Node("fake_target")
    {
        pub_ = this->create_publisher<sensor_msgs::msg::CompressedImage>(
            "/camera/image_raw/compressed", 1);
        timer_ = this->create_wall_timer(33ms, [this]() { publish(); });
    }

private:
    void publish()
    {
        // 黑背景 + 一个来回移动的红球
        cv::Mat img(480, 640, CV_8UC3, cv::Scalar(20, 20, 20));
        static double t = 0;
        t += 0.05;
        int x = 320 + (int)(200 * std::sin(t));
        int y = 240 + (int)(100 * std::sin(t * 0.7));
        cv::circle(img, cv::Point(x, y), 30, cv::Scalar(0, 0, 255), -1);

        std::vector<uchar> buf;
        cv::imencode(".jpg", img, buf);

        sensor_msgs::msg::CompressedImage msg;
        msg.format = "jpeg";
        msg.data = buf;
        pub_->publish(msg);
    }

    rclcpp::Publisher<sensor_msgs::msg::CompressedImage>::SharedPtr pub_;
    rclcpp::TimerBase::SharedPtr timer_;
};

int main(int argc, char** argv)
{
    rclcpp::init(argc, argv);
    rclcpp::spin(std::make_shared<FakeTarget>());
    rclcpp::shutdown();
    return 0;
}
```

（同样加进 CMakeLists：`add_executable(fake_target ...)` + `ament_target_dependencies(fake_target rclcpp sensor_msgs)` + 链接 OpenCV + install。）

## 6. 运行与测试

```bash
# 编译
cd ~/practice_ws
colcon build --packages-select mini_aim
source install/setup.bash

# 终端 1：假目标
ros2 run mini_aim fake_target

# 终端 2：瞄准节点
ros2 run mini_aim mini_aim

# 终端 3：看输出
ros2 topic echo /aim_offset
```

**预期结果：**

- 窗口里红球被绿框框住、红点标出重心、黄色十字是画面中心。
- 红球往右时 `dx` 为正、`yaw` 为正；往下时 `dy` 为正、`pitch` 为正。
- `/aim_offset` 持续更新。

**测试清单（都通过才算完）：**

| 测试 | 怎么测 | 通过标准 |
| --- | --- | --- |
| 找得到目标 | 红球在画面中 | 有绿框 |
| 偏移方向对 | 球往左移 | dx 变负 |
| 偏移方向对 | 球往上移 | dy 变负 |
| 丢目标不崩 | 把红球遮住 | 打印"没有找到目标"，程序不崩 |
| 角度随距离变 | 球离中心越远 | 角度越大 |

## 7. 升级方向（往校园赛靠拢）

这个小项目和校园赛项目的差距，就是"从入门到进阶"的差距：

| 现在的简化 | 升级 | 用到什么 |
| --- | --- | --- |
| 找"最大红色块" | 找"灯条"（细长形状筛选） | `minAreaRect` + 长宽比/角度 |
| 一个目标 | 灯条**配对**成装甲板 | 两两组合 + 距离条件 |
| 像素偏移算角度 | **PnP 精算距离和角度** | `solvePnP` + 相机内参 |
| 不知道敌人是谁 | **认数字**（1~8 号） | SVM + ROI 特征 |
| 发 String | 发标准 `SendData`（yaw/pitch/开火） | 自定义消息 |
| 固定的颜色范围 | 滑条/参数动态调 | `createTrackbar` / `declare_parameter` |

**建议：** 先把本项目的每一步改成上面的一格，改完你就有半个校园赛项目了。
完整版拆解见 `04-综合实战/00-校园赛项目全流程拆解.md`。
