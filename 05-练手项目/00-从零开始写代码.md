## 1. 写代码的正确姿势（五步法）

**记住这个流程，每次写代码都按它来：**

```
① 想清楚：要做什么？输入什么？输出什么？
        ↓
② 拆步骤：把大目标拆成几小步（用中文写注释）
        ↓
③ 搭骨架：先写空函数/空循环，确认能编译
        ↓
④ 填内容：一步一步填，填一步编译跑一次
        ↓
⑤ 验证：输入已知的数据，看输出对不对
```

**例子：写一个"算两点距离"的程序**

```cpp
#include <iostream>
#include <cmath>

// ① 目标：输入两个点的坐标，输出它们之间的距离
// ② 步骤：读入坐标 → 算 dx、dy → 套勾股定理 → 打印

int main()
{
    // ③④ 填内容
    double x1 = 0, y1 = 0, x2 = 3, y2 = 4;

    double dx = x2 - x1;
    double dy = y2 - y1;
    double dist = std::sqrt(dx*dx + dy*dy);

    std::cout << "距离 = " << dist << std::endl;   // ⑤ 应该输出 5
    return 0;
}
```

**两个铁律：**

1. **先把"要做什么"写成中文注释，再翻译成代码。**
2. **每写 5~10 行就编译运行一次**，别攒几百行。

## 2. 第一个程序：hello.cpp

```cpp
#include <iostream>

int main()
{
```

```bash
g++ hello.cpp -o hello
```

## 3. 练习 1：会计算的程序

### 目标

写一个程序：输入半径，输出圆的面积和周长。

### 思路

```
面积 = π × r²
周长 = 2 × π × r
```

### 参考代码

```cpp
#include <iostream>
#include <cmath>

int main()
{
    const double PI = 3.14159265;

    double r;
    std::cout << "输入半径：";
    std::cin >> r;

    double area = PI * r * r;
    double circle = 2 * PI * r;

    std::cout << "面积 = " << area << std::endl;
    std::cout << "周长 = " << circle << std::endl;
    return 0;
}
```

### 自己动手

1. 加上输入检查：`if (r <= 0) { cout << "半径必须为正"; return 1; }`
2. 改成求球体积 `4/3 π r³`（注意 `4/3` 是整数除法！写成 `4.0/3.0`）。
3. 让程序循环问 3 次。

## 4. 练习 2：会判断的程序

### 目标

写程序：输入一个成绩（0~100），输出等级（≥90 优，≥80 良，≥60 及格，否则不及格）。

### 参考代码

```cpp
#include <iostream>

int main()
{
    int score;
    std::cout << "输入成绩：";
    std::cin >> score;

    if (score >= 90) {
        std::cout << "优" << std::endl;
    } else if (score >= 80) {
        std::cout << "良" << std::endl;
    } else if (score >= 60) {
        std::cout << "及格" << std::endl;
    } else {
        std::cout << "不及格" << std::endl;
    }
    return 0;
}
```

### 自己动手

1. 打印 1~100 的所有偶数（for 循环 + `% 2 == 0`）。
2. 打印 1~100 的所有质数（双重循环，数约数个数）。
3. 用 while 循环让程序"输入 q 才退出"。

## 5. 练习 3：会封装的程序

### 目标

把"算距离"封装成函数 `pointdistance`，主程序调用它。

### 参考代码

```cpp
#include <iostream>
#include <cmath>

// 函数：算两点距离
double pointdistance(double x1, double y1, double x2, double y2)
{
    double dx = x2 - x1;
    double dy = y2 - y1;
    return std::sqrt(dx*dx + dy*dy);
}

int main()
{
    double d = pointdistance(0, 0, 3, 4);
    std::cout << "距离 = " << d << std::endl;   // 5
    return 0;
}
```

### 自己动手

1. 再写一个 `double toDegrees(double radians)`（弧度转角度：`×180/π`）。
2. 写一个 `bool isEven(int n)`。
3. 体会：**函数让主程序像"点菜"一样清楚** —— 这就是拆代码的意义。

## 6. 练习 4：会收集的程序

### 目标

输入一串数字（以 -1 结束），输出其中大于平均值的个数。

### 思路

```
先全部存进 vector → 算总和 → 算平均 → 再遍历数一遍
```

### 参考代码

```cpp
#include <iostream>
#include <vector>

int main()
{
    std::vector<int> nums;

    std::cout << "输入数字，-1 结束：\n";
    int x;
    while (std::cin >> x && x != -1) {
        nums.push_back(x);
    }

    if (nums.empty()) {
        std::cout << "没有输入" << std::endl;
        return 0;
    }

    int sum = 0;
    for (int n : nums) sum += n;
    double avg = (double)sum / nums.size();

    int count = 0;
    for (int n : nums)
        if (n > avg) count++;

    std::cout << "平均 = " << avg << "，大于平均的有 " << count << " 个\n";
    return 0;
}
```

### 自己动手

1. 改成输出**最大数**和**最小数**（提示：`std::max` / 或者用"打擂台"法）。
2. 把偶数挑出来放到另一个 vector。
3. 体会：**"先收集、再处理"是实战最常用的套路**（灯条、轮廓都是这样）。

## 7. 练习 5：会打包的程序

### 目标

定义 `struct Rect { double x, y, w, h; }`，写函数算面积，主程序创建两个矩形并比较。

### 参考代码

```cpp
#include <iostream>

struct Rect {
    double x, y;      // 左上角
    double w, h;      // 宽高
};

double area(const Rect& r) { return r.w * r.h; }

int main()
{
    Rect a{0, 0, 10, 5};    // 面积 50
    Rect b{0, 0, 3, 8};     // 面积 24

    std::cout << "a 面积 = " << area(a) << std::endl;
    std::cout << "b 面积 = " << area(b) << std::endl;
    std::cout << "较大的是 " << (area(a) > area(b) ? "a" : "b") << std::endl;
    return 0;
}
```

### 自己动手

1. 加一个成员函数 `center()` 返回中心点。
2. 写 `overlap(a, b)` 判断两个矩形是否重叠。
3. 体会：**struct 就是"把相关数据打包成一种新类型"** —— 校园赛的 `lightbar`、`Armor` 就是这么来的。

## 8. 练习 6：综合 —— 一个小计算器

### 目标

把前 5 个练习的技能全用上：输入算式 `数字 运算符 数字`，输出结果，支持循环输入。

### 参考代码

```cpp
#include <iostream>

double calculate(double a, char op, double b)
{
    switch (op) {
        case '+': return a + b;
        case '-': return a - b;
        case '*': return a * b;
        case '/':
            if (b == 0) {
                std::cout << "错误：不能除以 0\n";
                return 0;
            }
            return a / b;
        default:
            std::cout << "错误：不认识的运算符\n";
            return 0;
    }
}

int main()
{
    while (true) {
        double a, b;
        char op;
        std::cout << "输入算式（如 3 + 4），输入 q 退出：";
        if (!(std::cin >> a >> op >> b)) break;   // 输入失败（比如按了 q）就退出

        double result = calculate(a, op, b);
        std::cout << a << " " << op << " " << b << " = " << result << "\n\n";
    }
    std::cout << "再见！" << std::endl;
    return 0;
}
```

### 自己动手

1. 支持连续计算（用上一次的结果当 `a`）。
2. 加 `^`（乘方）运算符。
3. 加输入合法性检查（除 0 后别输出 0 当结果，加个成功标志）。

## 9. 怎么判断自己学会了

**不需要背语法。判断标准只有一个：**

> 不看教程，能不能独立写出"练习 6 的计算器"？

能 → 说明基本语法（变量、循环、判断、函数、struct）已经内化，可以进 OpenCV 了。
不能 → 回到对应小节，**自己再敲一遍**（不要复制粘贴）。

**再强调一次写代码五步法：**

```
想清楚（输入/输出） → 拆步骤（中文注释） → 搭骨架（能编译） → 填内容（小步跑） → 验证（已知数据）
```
